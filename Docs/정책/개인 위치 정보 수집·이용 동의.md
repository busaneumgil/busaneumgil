# 개인 위치 정보 수집·이용 동의

## 1. 수집·이용 항목

운영자는 다음의 개인 위치 정보를 수집·이용할 수 있습니다.

1. 현재 위치
2. 출발지
3. 도착지
4. 이동 경로
5. 주변 장소 탐색 정보
6. 위치 기반 제보 정보

## 2. 수집·이용 목적

개인 위치 정보는 다음 목적을 위해 사용됩니다.

1. 현재 위치 확인
2. 주변 장소 탐색
3. 출발지와 도착지 기반 경로 안내
4. 경로 주변 접근성 정보 제공
5. 위치 기반 제보 등록
6. 서비스 오류 확인 및 품질 개선

## 3. 보유 및 이용 기간

개인 위치 정보는 위치 기반 서비스 제공에 필요한 기간 동안 보유·이용되며, 이용자가 동의를 철회하거나 탈퇴하는 경우 지체 없이 파기합니다.

다만, 위치 정보의 보호 및 이용 등에 관한 법률 등 관련 법령에 따라 위치 정보 수집·이용·제공 사실 확인 자료를 보관해야 하는 경우 해당 법령에서 정한 범위 내에서 보관할 수 있습니다.

## 4. 동의 거부 권리 및 불이익

이용자는 개인 위치 정보 수집·이용에 대한 동의를 거부할 수 있습니다.

다만, 개인 위치 정보는 현재 위치 확인, 주변 장소 탐색, 경로 안내, 위치 기반 제보 등록을 위하여 필요한 정보이므로, 동의하지 않는 경우 서비스 이용이 제한될 수 있습니다.
