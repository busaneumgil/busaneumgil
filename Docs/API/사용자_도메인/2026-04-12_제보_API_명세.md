> **작성자:** 김응서  
> **최종 수정일:** 2026-04-29

## 1. API 목록

| 우선순위 | API | 설명 |
| --- | --- | --- |
| P1 | `POST /hazard-reports` | 도로 상태 제보 등록 |
| P1 | `GET /hazard-reports/me` | 내가 등록한 제보 목록 조회 |
| P1 | `GET /hazard-reports/me/{reportId}` | 내가 등록한 제보 상세 조회 |

> 제보 상태 변경(`PENDING` → `APPROVED`/`REJECTED`)은 사용자 API가 아니라 `POST /slack/hazard-reports/actions` 운영용 Slack 콜백 API에서 처리한다.
> 도로 상태 제보는 로그인 사용자 계정과 연결한다. 사용자 화면에는 처리 상태를 노출하지 않지만 서버는 운영 검토를 위해 상태를 관리한다.

## 2. 도로 상태 제보 등록

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/hazard-reports` |
| 인증 | 필요 |
| 설명 | 계단/단차, 점자블록, 인도 부재, 경사로, 인도폭 문제를 로그인 사용자 제보로 등록한다. 파일 업로드는 제외하고 이미지 URL 배열만 고려한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |
| Content-Type | Y | `application/json` |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| reportType | string | Y | 제보 유형. 후보값은 아래 `ReportType`을 따른다. |
| description | string | N | 설명 |
| reportPoint | object | Y | 제보 위치 |
| reportPoint.lat | number | Y | 위도 |
| reportPoint.lng | number | Y | 경도 |
| imageUrls | array | N | 제보 이미지 URL 목록. 선택 입력, 최대 5장 |

#### Request Example

```json
{
  "reportType": "SIDEWALK_MISSING",
  "description": "지도에는 인도로 나오지만 실제로는 보행 가능한 인도가 없습니다.",
  "reportPoint": {
    "lat": 35.1686,
    "lng": 129.0576
  },
  "imageUrls": [
    "https://example.com/reports/1/image-1.jpg"
  ]
}
```

### Response

- HTTP Status: `201 Created`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| reportId | Long | N | 제보 ID |

#### Success Example

```json
{
  "status": "S2010",
  "data": {
    "reportId": 1
  },
  "message": "생성되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | HR4000 | 제보 요청값이 올바르지 않습니다. | 제보 유형 또는 제보 위치 누락/형식 오류, 이미지 5장 초과 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |

### 처리 규칙

- 신규 제보는 서버 내부적으로 `PENDING` 상태로 생성한다.
- 사용자 API 응답에는 처리 상태를 내려주지 않는다.
- 제보 사진은 선택 입력이며 최대 5장이다.
- 제보 위치의 기준값은 `reportPoint`다. 주소 문자열은 역지오코딩 표시값이므로 MVP 요청/응답 및 DB 컬럼에서 제외한다.
- 등록된 제보는 지도/장소 정보에 바로 반영하지 않고 운영 검토 후 반영한다.

## 3. 내가 등록한 제보 목록 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/hazard-reports/me` |
| 인증 | 필요 |
| 설명 | 마이페이지에서 사용자가 등록한 제보 목록을 최신순으로 조회한다. 대표 사진만 내려준다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |

#### Query Parameter

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| page | int | N | 페이지 번호 |
| size | int | N | 페이지 크기 |

#### Body

> 없음

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| content | array | N | 제보 목록 |
| content[].reportId | Long | N | 제보 ID |
| content[].reportType | string | N | 제보 유형 |
| content[].reportPoint | object | N | 제보 좌표 |
| content[].createdAt | string | N | 등록 일시 |
| content[].representativeImageUrl | string | Y | 대표 사진 URL. 사진이 없으면 `null` |
| page | int | N | 현재 페이지 번호 |
| size | int | N | 페이지 크기 |
| totalElements | Long | N | 전체 데이터 수 |
| totalPages | int | N | 전체 페이지 수 |
| hasNext | boolean | N | 다음 페이지 존재 여부 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "content": [
      {
        "reportId": 1,
        "reportType": "SIDEWALK_MISSING",
        "reportPoint": {
          "lat": 35.1686,
          "lng": 129.0576
        },
        "createdAt": "2026-04-28T17:00:00+09:00",
        "representativeImageUrl": "https://example.com/reports/1/image-1.jpg"
      }
    ],
    "page": 0,
    "size": 10,
    "totalElements": 1,
    "totalPages": 1,
    "hasNext": false
  },
  "message": "정상 처리되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |

## 4. 내가 등록한 제보 상세 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/hazard-reports/me/{reportId}` |
| 인증 | 필요 |
| 설명 | 내가 등록한 제보 상세와 전체 사진을 조회한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |

#### Path Variable

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| reportId | Long | Y | 제보 ID |

#### Body

> 없음

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| reportId | Long | N | 제보 ID |
| reportType | string | N | 제보 유형 |
| description | string | Y | 설명 |
| reportPoint | object | N | 제보 좌표 |
| createdAt | string | N | 등록 일시 |
| imageUrls | array | N | 전체 사진 URL 목록 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "reportId": 1,
    "reportType": "SIDEWALK_MISSING",
    "description": "지도에는 인도로 나오지만 실제로는 보행 가능한 인도가 없습니다.",
    "reportPoint": {
      "lat": 35.1686,
      "lng": 129.0576
    },
    "createdAt": "2026-04-28T17:00:00+09:00",
    "imageUrls": [
      "https://example.com/reports/1/image-1.jpg",
      "https://example.com/reports/1/image-2.jpg"
    ]
  },
  "message": "정상 처리되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | HR4030 | 제보에 대한 권한이 없습니다. | 다른 사용자의 제보 조회 시도 |
| 404 | HR4040 | 제보를 찾을 수 없습니다. | 제보가 존재하지 않음 |

---

## 5. 공통 값 집합

### ReportType

| 값 | 표시명 |
| --- | --- |
| `STAIRS_STEP` | 계단/단차가 없다고 나와있는데 실제로 있음 |
| `BRAILLE_BLOCK` | 점자블록 |
| `SIDEWALK_MISSING` | 인도라고 적혀 있는데 실제로 없음 |
| `RAMP` | 경사로 |
| `SIDEWALK_WIDTH` | 인도폭 |
