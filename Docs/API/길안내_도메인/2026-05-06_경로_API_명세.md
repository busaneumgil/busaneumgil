# 경로 API 명세

> 작성일: 2026-05-06  
> 문서 목적: 백엔드/프론트 팀 공유용 API 계약  
> 범위: 도보 경로 검색, 대중교통 경로 검색, 경로 선택, 대중교통 도착정보 갱신, 경로 이탈 재탐색, 경로 평가

---

## 1. API 목록

| 우선순위 | API                                      | 설명                                  |
| -------- | ---------------------------------------- | ------------------------------------- |
| P1       | `POST /routes/search/walk`               | 도보-only 경로 후보 검색              |
| P1       | `POST /routes/search/transit`            | 대중교통 경로 후보 검색               |
| P1       | `POST /routes/{routeId}/select`          | 검색 후보 중 실제 안내할 경로 선택    |
| P1       | `POST /routes/{routeId}/transit-refresh` | 선택 경로의 버스/지하철 도착정보 갱신 |
| P1       | `POST /routes/reroute`                   | 현재 위치 기준 경로 이탈 재탐색       |
| P1       | `POST /route-ratings`                    | 안내받은 경로 별점 저장               |

## 2. 공통 규칙

### 2.1 인증

- 모든 경로 API는 로그인이 필요하다.
- 모든 요청은 `Authorization: Bearer {accessToken}` 헤더를 포함해야 한다.
- 백엔드는 토큰으로 사용자를 식별하고, user table의 `disabilityType`, `disabilityGrade`를 조회해 경로 탐색 조건에 반영한다.
- 사용자가 생성하거나 선택한 route만 후속 API에서 접근할 수 있다.
- 다른 사용자의 `routeId`, `searchId`, `routeSession`에 접근하면 `403 A4030`을 반환한다.

### 2.2 서비스 가능 영역

- 모든 좌표 입력값은 부산광역시 서비스 영역 안에 있어야 한다.
- 서비스 영역 밖 좌표는 외부 API까지 보내지 않고 백엔드 validation에서 차단한다.
- 서비스 영역 밖 좌표 오류는 `400 RT4003`을 반환한다.
- 프론트는 `RT4003`을 받으면 “부산광역시 안의 위치를 선택해 주세요.”를 표시한다.

### 2.3 시간값 의미

| 필드                  | 의미                                 |
| --------------------- | ------------------------------------ |
| `estimatedTimeMinute` | 경로 또는 leg의 예상 소요 시간       |
| `remainingMinute`     | 버스/지하철이 도착하기까지 남은 시간 |

`estimatedTimeMinute`는 도착예정 시간이 아니다. 프론트는 `estimatedTimeMinute`를 “소요 시간”으로 표시한다.

### 2.4 선택 경로

- 경로 검색 결과는 일정 시간 동안만 선택할 수 있다.
- 사용자가 경로를 선택하면 백엔드는 선택 경로 세션을 저장한다.
- 선택 경로 세션은 DB route session에 함께 저장된다.

### 2.5 도착정보 상태

`transit-refresh`는 도착분이 없어도 외부 API 호출과 정류장/노선 해석이 성공하면 성공 응답을 반환한다.

| arrivalStatus        | 의미                                                  | 프론트 표시                       |
| -------------------- | ----------------------------------------------------- | --------------------------------- |
| `REALTIME_AVAILABLE` | 실시간 도착예정분이 있음                              | “n분 뒤 도착예정”                 |
| `NO_CURRENT_ARRIVAL` | 정류장/노선은 맞지만 현재 도착 예정 차량 정보가 없음  | “현재 도착 예정 차량이 없습니다.” |
| `ARRIVAL_UNKNOWN`    | 제공기관 응답은 성공했지만 도착 여부를 판단할 수 없음 | “도착정보를 확인할 수 없습니다.”  |
| `SCHEDULE_BASED`     | 지하철 등 시간표 기반으로 남은 시간을 계산함          | “시간표 기준 n분 뒤 도착예정”     |

`NO_CURRENT_ARRIVAL`일 때 `transits`는 빈 배열이다.

### 2.6 재탐색 위치 검증

- 프론트는 현재 위치가 기존 경로에서 일정 거리 이상 벗어났다고 판단하면 `POST /routes/reroute`를 호출한다.
- reroute 요청에는 `currentLegSequence`를 보내지 않는다.
- 프론트는 `routeId`와 `currentPoint`만 보낸다.
- 백엔드는 저장된 route geometry와 `currentPoint`를 비교해 현재 leg를 추정하거나 full reroute 여부를 판단한다.
- 백엔드는 다음을 검증한다.
  - routeId 소유자 검증
  - currentPoint 부산 서비스 영역 검증
  - currentPoint가 기존 route 주변인지 검증
  - currentPoint가 기존 route와 지나치게 멀리 떨어져 있는지 검증
- 현재 위치가 말이 안 되게 멀거나 서비스 영역 밖이면 에러를 반환한다.

## 4. 프론트 에러 대응 표

| HTTP Status | status | message                                           | 발생 조건                                       | 프론트 대응                         |
| ----------- | ------ | ------------------------------------------------- | ----------------------------------------------- | ----------------------------------- |
| 400         | RT4000 | 경로 요청값이 올바르지 않습니다.                  | 좌표 누락, 형식 오류                            | 입력값 확인 안내                    |
| 400         | RT4003 | 부산광역시 안의 위치를 선택해 주세요.             | 좌표가 서비스 영역 밖                           | 지도/좌표 선택을 부산 영역으로 유도 |
| 400         | RT4004 | 출발지와 도착지를 다르게 선택해 주세요.           | 출발지와 도착지가 너무 가까움                   | 출발지/도착지 재선택 안내           |
| 400         | RT4005 | 현재 위치값이 올바르지 않습니다.                  | reroute currentPoint 누락/형식 오류             | 위치 권한 및 현재 위치 확인 안내    |
| 401         | A4010  | 인증이 필요합니다.                                | 토큰 누락/만료                                  | 로그인 또는 토큰 재발급             |
| 403         | A4030  | 접근할 수 없는 경로입니다.                        | 다른 사용자의 route/search/session 접근         | 재검색 또는 홈 이동                 |
| 404         | RT4040 | 탐색 가능한 경로가 없습니다.                      | 경로 후보 없음                                  | 조건 변경 후 재검색 안내            |
| 404         | RT4041 | 검색 결과가 만료되었습니다.                       | select 전 search 만료                           | 다시 검색 안내                      |
| 404         | RT4043 | 선택한 경로 정보가 만료되었습니다.                | route session 복구 불가                         | 다시 검색 안내                      |
| 409         | RT4091 | 현재 위치가 기존 경로에서 너무 멀리 벗어났습니다. | reroute currentPoint가 기존 route와 과도하게 멂 | 현재 위치 기준 새 검색 안내         |
| 409         | PT4090 | 대중교통 구간이 아닙니다.                         | WALK leg에 transit-refresh 요청                 | refresh 버튼 비활성화 또는 안내     |
| 502         | E5020  | 외부 경로 정보를 불러오지 못했습니다.             | ODsay, BIMS, 지하철, GraphHopper 호출 실패      | 잠시 후 재시도 안내                 |
| 504         | E5040  | 외부 경로 정보 응답이 지연되고 있습니다.          | 외부 API timeout                                | 재시도 버튼 노출                    |
| 500         | I5000  | 서버 오류가 발생했습니다.                         | 서버 내부 예외                                  | 일반 오류 안내                      |

> 프론트는 외부 API 제공기관 이름을 사용자에게 직접 노출하지 않는다. 백엔드는 provider, operation, request key를 로그에 남긴다.

## 5. POST /routes/search/walk

| 항목     | 내용                                                                                                                |
| -------- | ------------------------------------------------------------------------------------------------------------------- |
| 우선순위 | P1                                                                                                                  |
| Method   | `POST`                                                                                                              |
| URL      | `/routes/search/walk`                                                                                               |
| 인증     | 필요                                                                                                                |
| 설명     | 출발지와 도착지를 기준으로 도보-only 경로 후보를 탐색한다. 사용자 장애 유형/등급은 토큰 기반으로 백엔드가 조회한다. |

### Request

#### Header

| 이름          | 필수 | 설명               |
| ------------- | ---- | ------------------ |
| Authorization | Y    | Bearer 액세스 토큰 |
| Content-Type  | Y    | `application/json` |

#### Body

| 필드명         | 타입   | 필수 | 설명        |
| -------------- | ------ | ---- | ----------- |
| startPoint     | object | Y    | 출발지 좌표 |
| startPoint.lat | number | Y    | 출발지 위도 |
| startPoint.lng | number | Y    | 출발지 경도 |
| endPoint       | object | Y    | 도착지 좌표 |
| endPoint.lat   | number | Y    | 도착지 위도 |
| endPoint.lng   | number | Y    | 도착지 경도 |

#### Request Example

```json
{
  "startPoint": {
    "lat": 35.12,
    "lng": 128.936
  },
  "endPoint": {
    "lat": 35.1315,
    "lng": 128.8823
  }
}
```

### Response

#### Success

- HTTP Status: `200 OK`

#### Data Fields

| 필드명                                         | 타입   | Null 가능 | 설명                                                   |
| ---------------------------------------------- | ------ | --------- | ------------------------------------------------------ |
| searchId                                       | string | N         | 검색 결과 묶음 ID                                      |
| routes                                         | array  | N         | 도보 경로 후보 목록                                    |
| routes[].routeId                               | string | N         | 경로 후보 ID                                           |
| routes[].transportMode                         | string | N         | `WALK`                                                 |
| routes[].routeOption                           | string | N         | `SAFE`, `SHORTEST`                                     |
| routes[].title                                 | string | N         | 경로 표시명                                            |
| routes[].distanceMeter                         | number | N         | 총 거리                                                |
| routes[].estimatedTimeMinute                   | int    | N         | 예상 소요 시간                                         |
| routes[].badges                                | array  | N         | 경로 카드 요약 라벨                                    |
| routes[].geometry                              | string | N         | 전체 경로 geometry                                     |
| routes[].legs                                  | array  | N         | 이동수단 기준 큰 구간 목록                             |
| routes[].legs[].sequence                       | int    | N         | leg 순서                                               |
| routes[].legs[].type                           | string | N         | `WALK`                                                 |
| routes[].legs[].role                           | string | N         | `WALK_ONLY`                                            |
| routes[].legs[].instruction                    | string | N         | leg 요약 안내 문구                                     |
| routes[].legs[].distanceMeter                  | number | N         | leg 거리                                               |
| routes[].legs[].estimatedTimeMinute            | int    | Y         | leg 예상 소요 시간                                     |
| routes[].legs[].geometry                       | string | N         | leg geometry                                           |
| routes[].legs[].steps                          | array  | N         | 세부 안내 step 목록                                    |
| routes[].legs[].steps[].sequence               | int    | N         | step 순서                                              |
| routes[].legs[].steps[].instruction            | string | N         | 화면/TTS 안내 문구                                     |
| routes[].legs[].steps[].distanceMeter          | number | N         | step 거리                                              |
| routes[].legs[].steps[].geometry               | string | Y         | step geometry                                          |
| routes[].legs[].steps[].badges                 | array  | N         | step 라벨                                              |
| routes[].legs[].steps[].alerts                 | array  | N         | 안내 이벤트                                            |
| routes[].legs[].steps[].alerts[].type          | string | N         | 이벤트 타입. 예: `CROSSWALK`, `HIGH_SLOPE`, `CURB_GAP` |
| routes[].legs[].steps[].alerts[].distanceMeter | number | N         | step 시작점 기준 이벤트까지 거리                       |
| routes[].legs[].steps[].slopePercent           | number | Y         | 구간 대표 경사도                                       |
| routes[].legs[].steps[].widthState             | string | Y         | 보도 폭 상태                                           |

### 비고

- `accessibilityProfile`, `userId`, `destinationPlaceId`는 body로 받지 않는다.
- 백엔드는 토큰으로 사용자 접근성 프로필을 조회한다.
- 검색 결과는 일정 시간 동안만 선택할 수 있다.

## 11. 프론트 구현 메모

- 모든 API 요청에 Authorization 헤더를 포함한다.
- `estimatedTimeMinute`는 “소요 시간”으로 표시한다.
- `remainingMinute`는 `transit-refresh` 응답에서만 “도착예정”으로 표시한다.
- `arrivalStatus=NO_CURRENT_ARRIVAL`은 실패가 아니다.
- `RT4003`은 지도/좌표 선택 범위를 부산광역시 안으로 유도한다.
- `RT4041`, `RT4043`은 재검색 흐름으로 유도한다.
- `E5020`, `E5040`은 외부 API 제공기관명을 노출하지 않고 “잠시 후 다시 시도”로 안내한다.
- reroute 요청에는 `currentLegSequence`를 보내지 않는다.
