### A. 현재 이동 생활

**A1.** 일상적으로 혼자 외출하시는 편인가요? 주로 어떤 목적으로 이동하시나요?

> *예상 키워드: 병원, 마트, 복지관, 친구 방문, 여가 / 보호자 동반 여부*

&nbsp;

**A2.** 외출할 때 가장 불편하거나 두려운 상황은 어떤 경우인가요?

> *예상 키워드: 계단, 경사, 엘리베이터 고장, 좁은 보도, 공사 구간, 날씨*

&nbsp;

**A3.** 처음 가는 장소로 이동할 때 경로를 어떻게 파악하시나요? (길을 찾는 방법)

> *예상 키워드: 미리 검색, 아는 사람에게 물어봄, 직접 경험으로 파악, 길찾기 앱 사용*

&nbsp;

**A4.** 이동 중에 예상치 못한 장애물(공사, 막힌 경사로, 엘리베이터 고장 등)을 만난 경험이 있으신가요? 그때 어떻게 대처하셨나요?

&nbsp;

---

### B. 현재 앱/기술 사용 경험

**B1.** 길찾기 앱(네이버 지도, 카카오맵 등)을 사용해보신 적 있으신가요? 어떠셨나요?

> *사용하지 않는 경우: 이유도 함께 파악*

&nbsp;

**B2.** (사용 경험이 있다면) 기존 길찾기 앱에서 가장 아쉬웠던 점은 무엇인가요?

> *예상 키워드: 계단 포함 경로 안내, 경사 정보 없음, 장애인 화장실 위치 모름, 실제와 다른 정보*

&nbsp;

**B3.** 지도 앱에서 '전동휠체어로 이동 가능한 경로'만 보여준다면 실제로 사용하실 것 같으세요?

&nbsp;

---

### C. 서비스 기능 검증

**C1.** 이동 중에 가장 먼저 확인하고 싶은 시설 정보는 무엇인가요?

> *예상 키워드: 엘리베이터, 경사로, 장애인 화장실, 충전소, 접근 가능한 출입구*

&nbsp;

**C2.** 전동휠체어 충전소 위치 정보가 앱에 있다면 유용하게 쓰실 것 같으신가요? 현재 충전은 어떻게 해결하시나요?

&nbsp;

**C3.** 도로 공사나 엘리베이터 고장처럼 경로를 막는 상황을 앱에 직접 제보할 수 있다면 활용하실 의향이 있으신가요?

> *불편한 점이나 우려 사항도 함께 파악*

&nbsp;

**C4.** 자주 가는 경로(병원, 복지관 등)를 앱에 저장해두고 바로 꺼내 쓸 수 있다면 어떨 것 같으세요?

&nbsp;

**C5.** 두리발(장애인 콜택시)을 이용하시나요? 앱 안에서 두리발 연결 버튼이 있으면 편리할 것 같으신가요?

&nbsp;

---

### D. UI·접근성 선호도

**D1.** 스마트폰으로 지도나 앱을 사용할 때 손 조작이 불편하신 경우가 있으신가요?

> *예상 키워드: 한 손 조작, 버튼 크기, 화면 밝기, 글자 크기*

&nbsp;

**D2.** 앱을 쓸 때 음성 안내가 있는 편이 좋으신가요, 아니면 화면 정보만으로 충분하신가요?

&nbsp;

**D3.** 지도 화면보다 '근처 베리어프리 시설 목록'처럼 리스트 형태로 정보를 보여주는 방식이 더 편하실 것 같으신가요?

&nbsp;

### A. 이용자 이동 현황

**A1.** 담당하시는 분들이 외출·이동 시 가장 자주 겪는 어려움은 어떤 것인가요?

> *예상 키워드: 정보 부족, 경로 불확실, 동행자 필요, 심리적 불안, 물리적 장벽*

&nbsp;

**A2.** 이용자분들에게 이동 경로나 시설 정보를 문의받으실 때 주로 어떤 내용을 질문받으시나요?

> *예상 키워드: 엘리베이터 위치, 화장실, 휠체어 접근 식당, 저상버스 노선*

&nbsp;

**A3.** 현재 담당자 입장에서 이용자의 이동을 지원하기 위해 사용하시는 도구나 방법이 있으신가요?

&nbsp;

### B. 기존 서비스 한계

**B1.** 기존 길찾기 앱이나 장애인 관련 정보 서비스를 이용자에게 추천해보신 적 있으신가요? 실제로 얼마나 활용되고 있나요?

&nbsp;

**B2.** 이용자들이 앱 사용에서 어려움을 겪는 부분이 있다면 어떤 부분인가요?

> *예상 키워드: 정보 부정확, UI 복잡, 글자 크기, 조작 어려움, 신뢰 부족*

&nbsp;

**B3.** 공공 데이터(엘리베이터 위치, 화장실 등)의 정확도에 대해 어떻게 생각하시나요? 실제와 다른 경우를 경험하신 적 있으신가요?

&nbsp;

---

### C. 서비스 기능 검증

**C1.** 이용자들이 도로 공사, 경사로 막힘 등 현장 상황을 직접 앱에 제보할 수 있는 기능이 있다면, 실제로 활용될 것 같으신가요?

> *우려 사항도 함께 파악 — 잘못된 정보 제보, 운영 부담 등*

&nbsp;

**C2.** 이용자분들이 경로를 검색할 때 '계단 없는 경로', '경사 완만한 경로' 같은 조건을 설정할 수 있다면 얼마나 중요하게 생각하실 것 같으신가요?

&nbsp;

**C3.** 담당자 입장에서, 이용자의 이동 경로 데이터(동의 하에 수집)가 경로 개선에 활용된다는 것에 대해 어떻게 생각하시나요?

&nbsp;

**C4.** 응급 상황 시 보호자 또는 119에 현재 위치를 전송하는 기능이 있다면 이용자분들께 권장하실 의향이 있으신가요?

&nbsp;

---

### D. 서비스 방향성

**D1.** 이런 서비스가 있다면 이용자분들이 가장 먼저 쓰게 될 상황은 어떤 상황일 것 같으신가요?

&nbsp;

**D2.** 부산 지역에서 특히 이동이 불편한 구역이나 시설이 있다면 알려주실 수 있을까요?

> *구체적인 지역명이나 시설명 메모*

&nbsp;

**D3.** 이 서비스가 복지관 현장에서 실질적으로 도움이 되려면 어떤 기능이나 정보가 꼭 필요하다고 생각하시나요?

&nbsp;

**D4.** 담당자로서 이 서비스 개발팀에 꼭 전달하고 싶은 말씀이 있으시면 자유롭게 해주세요.
