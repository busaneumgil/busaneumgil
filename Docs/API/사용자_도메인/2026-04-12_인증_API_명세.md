## 1. API 목록

| 우선순위 | API | 설명 |
| --- | --- | --- |

## 2. 소셜 로그인

### 기본 정보

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/auth/social-login` |
| 인증 | 불필요 |
| 설명 | 소셜 제공자 토큰으로 로그인한다. 최초 로그인 사용자는 회원 정보를 생성한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Content-Type | Y | `application/json` |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| socialProvider | string | Y | 소셜 제공자. `KAKAO`, `NAVER`, `GOOGLE` |
| socialAccessToken | string | Y | 소셜 제공자에서 발급받은 액세스 토큰 |
| disabilityType | string | N | 장애 유형. `VISUAL`, `MOBILITY` |
| disabilityGrade | string | N | 장애 등급 |
| phoneNumber | string | N | 전화번호. 미입력 시 `119` 기본 처리 |

### Response

#### Success

- HTTP Status: `200 OK`

#### Data Fields

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| accessToken | string | N | 서비스 액세스 토큰 |
| refreshToken | string | N | 서비스 리프레시 토큰 |
| userId | Long | N | 사용자 ID |
| isNewUser | boolean | N | 최초 가입 여부 |
