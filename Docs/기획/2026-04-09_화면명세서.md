## 1. 최신 반영 원칙

| 구분 | 기준 |
| --- | --- |
| 사용자 용어 | 서비스 상위 용어는 `보행약자`로 통일한다. |
| 온보딩 | `ONB-001`~`ONB-005` 5단계로 구성하고, 서비스 소개는 3페이지 이상으로 제공한다. |
| 권한 | 위치 권한은 필수 안내 대상이다. 마이크 권한은 온보딩에서 요청하지 않고 STT 장소 검색 사용 시점에 요청한다. 알림은 MVP 제외 또는 후순위/미정이다. |
| 약관 | 약관 전문과 개인정보 화면은 노션 웹뷰로 표시한다. 노션 URL 제공 방식은 BE 확인 필요다. |
| 하단 탭 | `홈/북마크/제보/마이페이지` 4탭으로 통일한다. |
| 북마크 | 사용자 노출명은 `북마크`, 화면 ID는 `BMK-01` 장소 탭과 `BMK-02` 경로 탭으로 정리한다. |
| 목적지 설정 | `DEST-01`~`DEST-04` 별도 화면 ID 체계를 유지한다. 검색 결과 카드 선택 후에는 항상 지도 바텀시트 확인을 거친다. |
| 경로 | `ROUTE-01`은 경로 지도/탐색 결과, `ROUTE-02`는 경로 상세 정보, `NAV-01`은 길안내 진행이다. |
| 경로 옵션 | `안전한 길`, `최단거리` 2개만 제공하고 `ROUTE-01` 바텀시트에서 세로 카드로 나열한다. |
| 도착/평가 | 도착 완료 시 `ARR-01`로 이동하고, 진입 즉시 `ARR-02` 평가 모달을 자동 표시한다. |
| 제보 | `REPORT-01`~`REPORT-04` 단계형 플로우로 구성하고 제보는 사용자 계정과 연결한다. |
| 미확정 항목 | 확정되지 않은 정책은 `미정`, `추후 확정`, `추가 확인 필요`, `BE 확인 필요`로 남긴다. API URL, 필드, enum, 인증 상세는 임의 확정하지 않는다. |

## 3. 전역 화면 규칙

| 항목 | 규칙 |
| --- | --- |
| 앱 시작 gate | `authSession -> profileCompleted -> onboardingCompleted -> MAP-01` 순서로 분기한다. 로그인 화면 위치와 제공자 범위는 추가 확인 필요다. |
| 하단 탭 표시 | `MAP-01`, `DEST-01`~`DEST-04`, `ARR-01`, `BMK-01`~`BMK-02`, `REPORT-01`~`REPORT-04`, `MYP-01`~`MYP-03`에서 4탭을 표시한다. |
| 하단 탭 숨김 | 온보딩 5단계, `ROUTE-01`, `ROUTE-02`, `NAV-01`, `ARR-02`, `FAC-01` overlay에서는 숨긴다. |
| 검색 결과 | 카드 본문 선택은 바로 경로 설정으로 가지 않고 `DEST-03` 지도 바텀시트 확인으로 연결한다. |
| 접근성 라벨 | 검색 결과 카드, 시설 상세, 북마크 카드, 경로 요약은 FE 접근성 정보 라벨 가이드를 따른다. |
| BE 연동 | 서버가 필요한 항목은 `BE 확인 필요`로만 표시한다. API 상세는 본 문서에서 확정하지 않는다. |

## 4. 화면 상세 명세

### AUTH-001 로그인

| 항목 | 내용 |
| --- | --- |
| 목적 | 인증 세션이 없는 사용자의 앱 진입을 처리한다. |
| 주요 구성 | 서비스 로고, 로그인 제공자 버튼, 오류/로딩 상태, 접근성 안내 문구, 구글, 네이버, 카카오 |
| 액션 | 로그인 성공 시 프로필 완료 여부에 따라 `AUTH-002` 또는 `ONB-001`로 이동한다. |
| 미정 | 로그인 제공자 범위, 세션 만료 안내 방식은 추가 확인 필요다. |

### AUTH-002 프로필 설정 / 회원가입 완료

| 항목 | 내용 |
| --- | --- |
| 목적 | 최초 로그인 사용자의 필수 프로필 완료 조건을 처리한다. |
| 주요 구성 | 닉네임 또는 표시명, 사용자 유형 확인, 완료 CTA |
| 액션 | 프로필 완료 후 온보딩 미완료 사용자는 `ONB-001`로 이동한다. |
| BE 확인 필요 | 사용자 유형 값과 서버 프로필 필드 매핑은 BE 확인 필요다. |

### ONB-001 스플래시 / 시작

| 항목 | 내용 |
| --- | --- |
| 목적 | 서비스 진입과 온보딩 시작을 안내한다. |
| 주요 구성 | 브랜드/서비스명, 짧은 가치 설명, 시작하기 CTA, page indicator 초기 상태 |
| 액션 | 시작하기 선택 시 `ONB-002`로 이동한다. |
| 접근성 | 첫 포커스는 서비스명, 설명, 시작하기 CTA 순으로 둔다. |

### ONB-002 사용자 유형 선택

| 항목 | 내용 |
| --- | --- |
| 목적 | 보행약자 사용자 유형을 선택한다. |
| 주요 구성 | 사용자 유형 선택 카드, 선택 상태, 다음 CTA |
| 선택지 | `휠체어 사용자 (전동)`, `휠체어 사용자 (수동)`, `기타 보행약자` |
| 액션 | 선택 완료 시 `ONB-003`으로 이동한다. 마이페이지의 사용자 유형 변경도 이 화면을 재사용한다. |
| BE 확인 필요 | 위 3개 값의 서버 필드명과 enum 코드는 BE 확인 필요다. |

### ONB-003 권한 안내

| 항목 | 내용 |
| --- | --- |
| 목적 | 서비스 이용에 필요한 권한의 목적과 제한 사항을 안내한다. |
| 주요 구성 | 위치 권한 카드, 마이크 권한 안내 카드, 알림 후순위 안내, 계속 CTA |
| 권한 기준 | 위치는 필수 안내 대상이다. 마이크는 STT 장소 검색 사용 시점 요청으로 설명만 제공한다. 알림은 MVP 제외 또는 후순위/미정이다. |
| 액션 | 필수 권한 안내 확인 후 `ONB-004`로 이동한다. OS 권한 요청 시점은 추가 확인 필요다. |
| BE 확인 필요 | STT 처리 주체와 서버 연동 방식은 BE 확인 필요다. |

### ONB-004 약관 동의

| 항목 | 내용 |
| --- | --- |
| 목적 | 필수 약관 동의를 수집하고 전문 확인 동선을 제공한다. |
| 주요 구성 | 필수 약관 카드, 개인정보 안내, 동의 체크박스, 노션 웹뷰 진입, 동의하고 계속하기 CTA |
| 액션 | 필수 약관 동의 시 `ONB-005`로 이동한다. 미동의 시 CTA는 비활성이다. |
| BE 확인 필요 | 약관/개인정보 노션 URL 제공 방식은 BE 또는 기획 확인 필요다. |

### ONB-005 서비스 소개

| 항목 | 내용 |
| --- | --- |
| 목적 | 핵심 기능을 3페이지 이상 슬라이드로 소개하고 온보딩을 완료한다. |
| 주요 구성 | 무장애 경로, STT 장소 검색, 시민 제보 등 기능 카드, dot indicator, 다음/완료 CTA |

| 접근성 | 페이지 변경 상태를 텍스트와 indicator로 함께 전달한다. |

### MAP-01 지도 홈

| 항목 | 내용 |
| --- | --- |
| 목적 | 홈 탭의 기본 지도 화면과 주요 진입점을 제공한다. |
| 주요 구성 | 지도, 검색바, 마이크 아이콘, 접근성 필터, 현재 위치 버튼, 날씨/미세먼지 카드, 최근 목적지, 하단 4탭 |
| 액션 | 검색바 선택 시 `DEST-01`, 마이크 아이콘 선택 시 STT 기반 장소 검색으로 진입한다. 마이크 권한은 이 시점에 요청한다. |
| 최근 목적지 | 전체보기는 별도 전체 목록 화면이 아니라 `BMK-01`로 연결한다. |
| 날씨/미세먼지 | 미세먼지 영역 chevron은 날씨 외부 정보 패널로 이동한다. |
| 미정 | 접근성 필터 `더보기` 포함 항목은 미정이다. |

### FAC-01 시설 상세 바텀시트

| 항목 | 내용 |
| --- | --- |
| 목적 | 지도 또는 북마크에서 선택한 장소의 상세 정보를 확인한다. |
| 주요 구성 | 장소명, 주소, 접근성 정보 라벨, 북마크 토글, 길찾기 CTA, 닫기 |
| 액션 | 길찾기 선택 시 `DEST-03`에서 목적지 바텀시트를 확인한 뒤 `ROUTE-01`로 이동한다. |
| BE 확인 필요 | 장소 식별자, 좌표, 접근성 정보 라벨 데이터 제공 방식은 BE 확인 필요다. |

### DEST-01 목적지 검색 및 최근 방문지

| 항목 | 내용 |

## 6. MVP 제외 또는 후순위

- 알림함, 공지함, 메시지 inbox 화면은 MVP에서 생성하지 않는다.
- 별도 최근 목적지 전체 목록 화면은 만들지 않고 북마크 화면으로 연결한다.
- 길안내 중도 종료 정책은 미정이다.
- 접근성 필터 `더보기` 포함 항목은 미정이다.
- 사용자 상태 설문 노출 조건과 저장 위치는 추가 확인 필요다.
- 시각 지원 전용 `VIS-01`~`VIS-04` 흐름은 후속 접근성 확장 후보로 둔다.
