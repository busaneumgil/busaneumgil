# 📋 제보 API 명세

> **작성일:** 2026-04-12  
> **작성자:** 김응서  
> **최종 수정일:** 2026-04-12

---

## 1. API 목록

| 우선순위 | API | 설명 |
| --- | --- | --- |
| P1 | `POST /hazard-reports` | 도로 상태 제보 등록 |
| P2 | `GET /hazard-reports/me` | 내 제보 목록 조회 |
| P2 | `GET /hazard-reports/{reportId}` | 제보 상세 조회 |
| P2 | `PATCH /hazard-reports/{reportId}` | 제보 수정 |
| P2 | `DELETE /hazard-reports/{reportId}` | 제보 삭제/취소 |

> 제보 상태 변경(`PENDING` → `APPROVED`/`REJECTED`)은 사용자 API가 아니라 `POST /slack/hazard-reports/actions` 운영용 Slack 콜백 API에서 처리한다.

## 2. 도로 상태 제보 등록

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/hazard-reports` |
| 인증 | 필요 |
| 설명 | 도로 공사, 장애물, 점자블록 손상 등을 제보한다. 파일 업로드는 제외하고 이미지 URL 배열만 고려한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |
| Content-Type | Y | `application/json` |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| reportType | string | Y | 제보 유형. `CONSTRUCTION`, `OBSTACLE`, `DAMAGE`, `OTHER` |
| description | string | N | 설명 |
| reportPoint | object | Y | 제보 위치 |
| reportPoint.lat | number | Y | 위도 |
| reportPoint.lng | number | Y | 경도 |
| address | string | N | 주소 |
| imageUrls | array | N | 제보 이미지 URL 목록 |

#### Request Example

```json
{
  "reportType": "OBSTACLE",
  "description": "보도 중앙에 이동을 방해하는 적치물이 있습니다.",
  "reportPoint": {
    "lat": 35.1686,
    "lng": 129.0576
  },
  "address": "부산광역시 부산진구 시민공원로 73",
  "imageUrls": [
    "https://example.com/reports/1/image-1.jpg"
  ]
}
```

### Response

- HTTP Status: `201 Created`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| reportId | Long | N | 제보 ID |
| status | string | N | 제보 상태. 기본값 `PENDING` |

#### Success Example

```json
{
  "success": true,
  "data": {
    "reportId": 1,
    "status": "PENDING"
  },
  "message": null
}
```

### Error

| HTTP Status | code | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | INVALID_INPUT | 잘못된 입력입니다. | 제보 유형 또는 제보 위치 누락/형식 오류 |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 누락/만료 |

## 3. 내 제보 목록 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P2 |
| Method | `GET` |
| URL | `/hazard-reports/me` |
| 인증 | 필요 |
| 설명 | 현재 사용자가 등록한 제보 목록을 조회한다. 관리자 화면에서는 사용자 정보를 익명 처리한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |

#### Query Parameter

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| page | int | N | 페이지 번호 |
| size | int | N | 페이지 크기 |
| status | string | N | 제보 상태. `PENDING`, `APPROVED`, `REJECTED` |

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| content | array | N | 제보 목록 |
| content[].reportId | Long | N | 제보 ID |
| content[].reportType | string | N | 제보 유형 |
| content[].address | string | Y | 주소 |
| content[].status | string | N | 제보 상태 |
| page | int | N | 현재 페이지 번호 |
| size | int | N | 페이지 크기 |
| totalElements | Long | N | 전체 데이터 수 |
| totalPages | int | N | 전체 페이지 수 |
| hasNext | boolean | N | 다음 페이지 존재 여부 |

#### Success Example

```json
{
  "success": true,
  "data": {
    "content": [
      {
        "reportId": 1,
        "reportType": "OBSTACLE",
        "address": "부산광역시 부산진구 시민공원로 73",
        "status": "PENDING"
      }
    ],
    "page": 0,
    "size": 10,
    "totalElements": 1,
    "totalPages": 1,
    "hasNext": false
  },
  "message": null
}
```

### Error

| HTTP Status | code | message | 발생 조건 |
| --- | --- | --- | --- |
| 401 | UNAUTHORIZED | 인증이 필요합니다. | 토큰 누락/만료 |

## 5. 제보 수정

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P2 |

| URL | `/hazard-reports/{reportId}` |

### Request

#### Header

| 이름 | 필수 | 설명 |

| --- | --- | --- | --- |
| reportId | Long | Y | 제보 ID |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| reportType | string | N | 제보 유형 |
| description | string | N | 설명 |
| reportPoint | object | N | 제보 위치 |
| address | string | N | 주소 |

```json

{
```

```json
    "reportId": 1,
```

| HTTP Status | code | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | INVALID_INPUT | 잘못된 입력입니다. | 수정 필드 형식 오류 |
