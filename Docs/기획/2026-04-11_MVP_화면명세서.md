## 1. MVP 범위 원칙

| 항목 | MVP 기준 |
| --- | --- |
| 앱 진입 | `authSession -> onboardingCompleted -> MAP-01` 순서로 분기한다. 인증 세션이 없으면 `AUTH-001`로 이동한다. |
| 로그인 | `AUTH-001`은 필수 로그인 화면이며 카카오/네이버/구글 소셜 로그인만 제공한다. production 기준 `비로그인으로 계속`, guest mode는 제공하지 않는다. |
| 온보딩 | `ONB-001`~`ONB-005` 5단계. 서비스 소개는 3페이지 이상이다. |
| 사용자 유형 | 상위 용어는 `보행약자`로 통일하고, 세부 이동 특성은 `휠체어 사용자 (전동)`, `휠체어 사용자 (수동)`, `기타 보행약자`로 정리한다. |
| 장애등급 | 온보딩 필수 단계에서 제거한다. |
| 권한/약관 | 마이크 권한은 온보딩에서 요청하지 않는다. 약관 전문은 노션 웹뷰로 표시한다. |
| 하단 탭 | `홈/북마크/제보/마이페이지` 4탭으로 고정한다. |
| 경로 | `ROUTE-01`의 대중교통 탭은 MVP에 포함한다. 경로 옵션은 `안전한 길`, `최단거리` 2개만 사용한다. |
| 제보 | 제보는 사용자 계정과 연결하고, 제보 처리 상태는 화면에 노출하지 않는다. |
| 데이터 책임 | 서버 데이터가 기준이며 로컬은 `cache/offline/pending` 보조 역할로만 사용한다. |
| BE 연동 | API 상세는 임의 확정하지 않고 `BE 확인 필요`로 남긴다. |

## 3. 핵심 플로우

### 3.1 온보딩

| 순서 | 화면 | 핵심 동작 |
| --- | --- | --- |
| 1 | ONB-001 | 시작하기 선택 |
| 2 | ONB-002 | `휠체어 사용자 (전동)`, `휠체어 사용자 (수동)`, `기타 보행약자` 중 선택 |
| 3 | ONB-003 | 위치 권한 필요성을 안내한다. 마이크는 STT 장소 검색 사용 시점 요청으로 안내만 한다. |
| 4 | ONB-004 | 필수 약관 동의. 전문은 노션 웹뷰로 확인한다. |
| 5 | ONB-005 | 3페이지 이상 서비스 소개 완료 후 `MAP-01`로 이동 |

### 3.2 지도 홈과 목적지 설정

| 출발 | 조건 | 도착 |
| --- | --- | --- |
| MAP-01 | 검색바 선택 | DEST-01 |
| MAP-01 | 마이크 아이콘 선택 | STT 장소 검색 진입, 마이크 권한 사용 시점 요청 |
| MAP-01 | 최근 목적지 전체보기 | BMK-01 |
| MAP-01 | 미세먼지 chevron | 날씨 외부 정보 패널 |
| DEST-01 | 검색 실행 | DEST-02 |
| DEST-02 | 검색 결과 카드 선택 | DEST-03 |
| DEST-03 | 도착지로 설정 + 설문 필요 | DEST-04 |
| DEST-03 | 도착지로 설정 + 설문 불필요 | ROUTE-01 |

### 3.3 경로와 길안내

| 화면 | MVP 동작 |
| --- | --- |
| ROUTE-01 | 도보/대중교통 탭을 제공한다. 대중교통 탭은 MVP에 포함한다. |
| ROUTE-01 | 경로 옵션은 `안전한 길`, `최단거리` 2개 카드만 세로로 나열한다. |
| ROUTE-01 | 옵션 카드 본문 선택은 선택 상태 변경이고, 우측 상단 화살표가 `ROUTE-02` 상세 진입이다. |
| ROUTE-01 | 길 안내 시작 선택 시 `NAV-01`로 이동한다. |
| NAV-01 | 경로 이탈 상태는 재검색/재탐색으로 정리한다. |
| NAV-01 | 도착 완료 시 `ARR-01`로 이동한다. 중도 종료 정책은 미정이다. |
| ARR-01 | 진입 즉시 `ARR-02` 평가 모달을 자동 표시한다. |
| ARR-02 | 우측 상단 X 버튼으로 평가를 건너뛸 수 있다. 평가 저장 API는 신규 예정/추후 구현이다. |

### 3.4 북마크

| 화면 | MVP 동작 |
| --- | --- |
| BMK-01 | 장소 북마크 탭. 카드 본문 선택 시 장소 상세로 이동한다. |

## 4. MVP 미정 / BE 확인 필요

| 영역 | 내용 |
| --- | --- |
| 로그인 UX 순서 | 시스템 gate는 `authSession -> onboardingCompleted -> MAP-01`로 고정한다. 다만 `AUTH-001`과 `ONB-001`의 시각적 첫 노출 순서는 최종 UX 확정이 필요하다. |
| 권한 | 권한 안내 화면에서 OS 권한을 카드 선택 시 요청할지, 하단 CTA에서 일괄 요청할지 미정 |
| 접근성 필터 | `더보기` 포함 항목 미정 |
| 사용자 상태 설문 | 노출 조건과 상태 저장 위치 추가 확인 필요 |
| STT | 처리 주체와 서버 연동 방식 BE 확인 필요 |
| 약관 | 노션 URL 제공 방식 BE 또는 기획 확인 필요 |
| 대중교통 | 후보 조회, 저상버스/역 접근성 검증 범위, 외부 API 연동 범위 BE 확인 필요 |
| 재탐색 | 현재 위치 기준 재검색/재탐색 계약 BE 확인 필요 |
| 평가 | 평가 저장 API는 신규 예정/추후 구현. 상세 계약 BE 확인 필요 |
| 북마크 | 경로 북마크 즉시 길안내에 필요한 payload BE 확인 필요 |
| 제보 | 제보 유형 enum, imageUrl 업로드, 사용자 계정 연결, 상태 숨김 처리 BE 확인 필요 |
| 활동/계정 | 활동 배지 산정, 로그아웃 정책, 회원탈퇴 재인증/데이터 처리 BE 확인 필요 |

## 5. MVP 제외 또는 후순위

- `SCR-001`~`SCR-003`, `ONB-01`~`ONB-03` 같은 구 온보딩 구조는 사용하지 않는다.
- production 기준 `비로그인으로 계속`, 게스트 모드, 로그인 없이 지도/경로/북마크/제보 진입은 제거한다.
- 3탭 또는 5탭 후보 구조는 사용하지 않고 `홈/북마크/제보/마이페이지` 4탭만 유지한다.
- 알림은 MVP 제외 또는 후순위/미정으로 둔다.
- 별도 최근 목적지 전체 목록 화면은 제공하지 않는다.
- 제보 처리 상태 화면은 제공하지 않는다.
- 북마크 정렬, 전체 선택, 다중 선택은 제공하지 않는다.
- 길안내 중도 종료 정책은 이번 MVP에서 확정하지 않는다.
- 고객센터/1:1 문의 실제 연결은 제공하지 않고 `준비중인 기능입니다.` 메시지만 표시한다.
- `local-first`나 로컬 source of truth 표현은 production 핵심 정책으로 사용하지 않는다.
- 시각 지원 전용 `VIS-01`~`VIS-04` 흐름은 후속 접근성 확장 후보로 둔다.
