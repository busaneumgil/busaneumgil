## 1. API 목록

| 우선순위 | API | 설명 |
| --- | --- | --- |
| P1 | `GET /admin/me` | 관리자 principal 조회 |
| P1 | `GET /admin/areas` | 관리자 검수 구/동 목록 조회 |
| P1 | `GET /admin/road-network/segments` | 관리자 보행 네트워크 조회 |
| P1 | `GET /admin/places/facilities` | 관리자 편의시설 조회 |
| P1 | `GET /admin/hazard-reports` | 관리자 제보 목록 조회 |
| P1 | `GET /admin/hazard-reports/{reportId}` | 관리자 제보 상세 조회 |
| P1 | `PATCH /admin/hazard-reports/{reportId}/approve` | 제보 승인 |
| P1 | `PATCH /admin/hazard-reports/{reportId}/reject` | 제보 반려 |

> 관리자 API도 API 전용 서브도메인 기준으로 노출하므로 기본 path prefix로 `/api`를 붙이지 않는다.
> 관리자 기능은 로그인 사용자 중 `users.role=ADMIN`인 계정만 사용할 수 있다.
> 백엔드는 해당 사용자에게 Spring Security `ROLE_ADMIN` 권한을 부여하고 `/admin/**`를 `ADMIN` 권한으로 제한한다.
> 관리자 지도 화면은 CSV editor 서버를 호출하지 않고, 백엔드 RDB 조회 API만 사용한다.
> 구/동 selector와 보행 네트워크 필터를 사용하려면 행정동 GeoJSON을 `admin_areas`에 먼저 적재해야 한다.
> dev/prod 적재 스크립트는 각각 `scripts/db/load_admin_areas_dev.sh`, `scripts/db/load_admin_areas_prod.sh`를 사용한다.
> 편의시설 조회를 사용하려면 `places_erd.csv`, `place_accessibility_features_erd.csv`를 `scripts/db/load_places_dev.sh` 또는 `scripts/db/load_places_prod.sh`로 먼저 적재해야 한다.

## 2. 관리자 principal 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/admin/me` |
| 인증 | 필요 |
| 설명 | 현재 로그인한 관리자 principal과 permission 목록을 조회한다. |

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| userId | UUID | N | 사용자 ID |
| role | string | N | 관리자 권한. `ADMIN` |
| permissions | array | N | 관리자 permission 목록 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "userId": "019df09d-ce19-78f0-b331-4ec38ae99ce5",
    "role": "ADMIN",
    "permissions": [
      "HAZARD_REPORT_READ",
      "HAZARD_REPORT_REVIEW"
    ]
  },
  "message": "정상 처리되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | A4030 | 권한이 없습니다. | `users.role`이 `ADMIN`이 아님 |

## 3. 관리자 검수 구/동 목록 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/admin/areas` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 관리자 보행 네트워크 검수 화면에서 사용할 구/동 목록을 조회한다. |

### 처리 규칙

- `admin_areas.gu`, `admin_areas.dong`에 값이 있는 행만 목록에 포함한다.
- `admin_areas`는 관리자 검수 화면의 구/동 selector와 보행 네트워크 공간 필터에 사용한다.
- `gu`, `dong`은 `road_segments` 컬럼이 아니다.
- `명지1동`, `명지2동`처럼 숫자 동이 있는 경우 기존 관리자 화면과 동일하게 `명지동` 형태의 묶음 선택지를 함께 제공할 수 있다.

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| areas | array | N | 구/동 목록 |
| areas[].gu | string | N | 구 |
| areas[].dong | string | N | 동 |

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | A4030 | 권한이 없습니다. | `users.role`이 `ADMIN`이 아님 |

## 4. 관리자 보행 네트워크 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/admin/road-network/segments` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 행정동 경계와 교차하는 DB `road_segments`를 관리자 지도 렌더링용 GeoJSON payload로 조회한다. |

### Request

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| gu | string | N | 구 필터. `dong`과 함께 있을 때 `admin_areas` 경계 기준으로 적용 |
| dong | string | N | 동 필터. `gu`와 함께 있을 때 `admin_areas` 경계 기준으로 적용. 숫자 동 묶음 선택지는 해당 숫자 동들을 함께 조회 |
| limit | int | N | 조회 개수. 기본값 `10000`, 허용 범위 `1`~`20000` |

### 처리 규칙

- `gu`, `dong`이 모두 있으면 `admin_areas.geom` 기준 500m buffer의 bounding box와 교차하는 `road_segments`를 조회한다.
- 이는 기존 CSV 관리자 서버가 행정동 GeoJSON에서 bbox를 계산해 segment를 필터링하던 방식을 DB 기반으로 옮긴 것이다.
- `gu` 또는 `dong`이 없으면 전체 `road_segments` 중 `limit`만큼 조회한다.

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| summary.segmentCount | long | N | 조건에 맞는 전체 segment 개수 |
| summary.visibleSegmentCount | int | N | 응답에 포함된 segment 개수 |
| bbox | array | Y | `[minLng, minLat, maxLng, maxLat]`. 조회 결과가 없으면 `null` |
| segments.type | string | N | `FeatureCollection` |
| segments.features[].geometry.type | string | N | `LineString` |
| segments.features[].properties.edgeId | Long | N | segment ID |
| segments.features[].properties.segmentType | string | N | `SIDE_LINE`, `CROSS_WALK` |

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | C4000 | 잘못된 입력입니다. | `limit`이 허용 범위를 벗어남 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | A4030 | 권한이 없습니다. | `users.role`이 `ADMIN`이 아님 |

## 6. 관리자 제보 목록 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/admin/hazard-reports` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 관리자 페이지에서 도로 상태 제보 목록을 최신순으로 조회한다. |

### Request

#### Query Parameter

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| status | string | N | 처리 상태 필터. `PENDING`, `APPROVED`, `REJECTED` |
| cursor | Long | N | 마지막으로 조회한 제보 ID. 첫 조회 시 생략 |
| size | int | N | 조회 개수. 기본값 `10`, 허용 범위 `1`~`100` |

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| content | array | N | 제보 목록 |
| content[].reportId | Long | N | 제보 ID |
| content[].reporterUserId | UUID | N | 제보자 사용자 ID |
| content[].reportType | string | N | 제보 유형 |
| content[].reportPoint | object | N | 제보 좌표 |
| content[].status | string | N | 처리 상태 |
| content[].createdAt | string | N | 등록 일시 |
| content[].representativeImageUrl | string | Y | 대표 사진 URL. 사진이 없으면 `null` |
| size | int | N | 조회 개수 |
| nextCursor | Long | Y | 다음 조회에 사용할 cursor. 다음 데이터가 없으면 `null` |
| hasNext | boolean | N | 다음 데이터 존재 여부 |

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | C4000 | 잘못된 입력입니다. | `status`, `cursor`, `size` 값이 허용 범위를 벗어남 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | A4030 | 권한이 없습니다. | `users.role`이 `ADMIN`이 아님 |
