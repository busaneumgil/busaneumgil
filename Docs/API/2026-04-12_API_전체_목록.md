## 3. API 목록

| 우선순위 | 대분류 | 소분류 | API | 포함 기능 | 판단 |
| --- | --- | --- | --- | --- | --- |
| P1 | 사용자 도메인 | 인증 | `POST /auth/social-login` | 소셜 토큰 검증 및 기존 회원 로그인 | 기존 회원은 토큰을 발급하고, 신규 사용자는 `signupToken`만 반환 |
| P1 | 사용자 도메인 | 인증 | `POST /auth/signup` | 회원가입 완료 | `signupToken`, 1차 사용자 유형, 조건부 보행약자 세부 유형, 필수 약관 동의 확인 후 `users` row 생성 |
| P1 | 사용자 도메인 | 인증 | `POST /auth/reissue` | 토큰 재발급 | 유지 |
| P1 | 사용자 도메인 | 인증 | `POST /auth/logout` | 로그아웃 | 유지 |
| P2 | 사용자 도메인 | 인증 | `DELETE /users/me` | 회원탈퇴 | 기능명세서에는 있음. MVP 화면에서는 제외지만 개인정보 기능이라 후보로 둠 |
| P1 | 사용자 도메인 | 사용자 정보/설정 | `GET /users/me` | 내 정보 조회 | 유지 |
| P2 | 사용자 도메인 | 사용자 정보/설정 | `PATCH /users/me/user-type` | 사용자 유형 수정 | 마이페이지에서 1차 사용자 유형과 조건부 보행약자 세부 유형을 수정 |
| P1 | 사용자 도메인 | 북마크 | `GET /bookmarks` | 장소 북마크 목록 조회 | 로그인 사용자의 서버 DB 조회 |
| P1 | 사용자 도메인 | 북마크 | `POST /bookmarks` | 장소 북마크 등록 | 내부 `places.placeId`가 있는 장소만 서버 북마크로 저장 |
| P1 | 사용자 도메인 | 북마크 | `DELETE /bookmarks/places/{placeId}` | 장소 북마크 해제 | 로그인 사용자의 서버 DB 삭제 |
| P1 | 사용자 도메인 | 경로 북마크 | `GET /favorite-routes` | 경로 북마크 목록 조회 | 로그인 사용자의 서버 DB 조회. 최신순 |
| P1 | 사용자 도메인 | 경로 북마크 | `POST /favorite-routes` | 경로 북마크 저장 | 출발지/도착지/옵션만 저장. 실제 경로 상세는 저장하지 않음 |
| P1 | 사용자 도메인 | 경로 북마크 | `PATCH /favorite-routes/{favRouteId}` | 경로 북마크 수정 | 출발지/도착지/옵션 수정 |
| P1 | 사용자 도메인 | 경로 북마크 | `DELETE /favorite-routes/{favRouteId}` | 경로 북마크 삭제 | 로그인 사용자의 서버 DB 삭제 |
| P1 | 사용자 도메인 | 제보 | `POST /hazard-reports` | 도로 상태 제보 등록 | 로그인 사용자 계정과 연결. 사진 선택, 최대 5장 |
| P1 | 사용자 도메인 | 제보 | `GET /hazard-reports/me` | 내가 등록한 제보 목록 조회 | 마이페이지 제보 목록. 최신순, 대표 사진 1장, 처리 상태 미노출 |
| P1 | 사용자 도메인 | 제보 | `GET /hazard-reports/me/{reportId}` | 내가 등록한 제보 상세 조회 | 전체 사진 목록 조회. 처리 상태 미노출 |
| P1 | 장소 도메인 | 장소/지도 | `GET /places` | 주변 시설 마커 조회, 장소 카테고리/접근성 필터 | `category`는 더보기, `featureType`은 빠른 접근성 필터 |
| P1 | 장소 도메인 | 장소/지도 | `GET /places/{placeId}` | 시설 상세 조회, 접근성 정보 조회 | `place_accessibility_features`까지 응답에 포함 |
| P1 | 장소 도메인 | 장소 검색 | `GET /places/search` | 텍스트 장소 검색 | 카카오 API 연동, 내부 `places.providerPlaceId` 매칭. 음성 흐름에서는 `/voice/analyze`로 확정된 `placeName`을 `keyword`로 전달 |
| P1 | 음성 도메인 | 음성 분석 | `POST /voice/analyze` | STT 텍스트 의미 분석 | AI 서버가 의도와 장소명을 추출. 보행약자는 장소명 추출 후 바로 검색, 저시력자는 TTS 확인 후 검색 |
| P1 | 보행 네트워크 도메인 | 경로 | `POST /routes/search` | 경로 탐색, 최단/안전 경로 비교, 경로 구간 정보, 위험도 정보, TTS 안내 문구 | Query Parameter 없음. Body의 `routeOptions`는 선택값. 없으면 `SAFE`, `SHORTEST` 둘 다 반환 |
| P1 | 보행 네트워크 도메인 | 경로 평가 | `POST /route-ratings` | 도착 직후 경로 별점 평가 저장 | 방금 안내받은 경로에 별점만 저장. 의견 텍스트와 저장 경로 평가는 제외 |
| P2 | 보행 네트워크 도메인 | 경로 | `POST /routes/reroute` | 경로 이탈 재탐색 | 현재 위치, 도착지, 기존 옵션 기준으로 재탐색 |
| P2 | 대중교통 도메인 | 버스 정류소 | `GET /public-transit/bus/stops` | 버스 정류소 검색 | 부산 BIMS 정류소 식별자 확보용. 정류소명/ARS 번호 중심, 주변 정류장 후보는 카카오 장소 검색 또는 정류소 캐시와 매칭 |
| P2 | 대중교통 도메인 | 버스 노선 | `GET /public-transit/bus/routes/{routeId}/stops` | 노선 정류장 순서 및 실시간 버스 위치 조회 | 부산 BIMS `busInfoByRouteId` 연동. 직행/환승 구간 검증에 사용 |
| P2 | 대중교통 도메인 | 버스 도착 정보 | `GET /public-transit/bus/stops/{busStopId}/arrivals` | 정류소 도착 정보 조회 | 부산 BIMS `stopArrByBstopid` 연동. `routeId` query가 있으면 특정 노선만 필터링 |
| P2 | 대중교통 도메인 | 접근성 경로 | `POST /public-transit/accessible-route-candidates` | 접근성 대중교통 경로 후보 조회 | ODsay 등 외부 대중교통 길찾기 API와 부산 BIMS/부산교통공사 데이터를 조합. Version A 직행, Version B 환승 포함 PoC 필요 |
| P1 | 운영 도메인 | Slack 제보 검토 | `POST /slack/hazard-reports/actions` | Slack 제보 승인/반려 처리 | Slack 버튼 콜백으로 `hazard_reports.status`를 `APPROVED` 또는 `REJECTED`로 변경 |

## 5. 공통 응답 형식

### Success

```json
{
  "status": "S2000",
  "data": {},
  "message": "정상 처리되었습니다."
}
```

### Error

```json
{
  "status": "C4000",
  "message": "잘못된 입력입니다."
}
```

## 6. 공통 Error Code

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | C4000 | 잘못된 입력입니다. | 요청값 검증 실패 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | A4030 | 권한이 없습니다. | 권한 없음 |
| 404 | C4040 | 리소스를 찾을 수 없습니다. | 조회 대상 없음 |
| 409 | C4090 | 이미 처리된 요청입니다. | 중복/상태 충돌 |
| 500 | I5000 | 서버 내부 오류가 발생했습니다. | 서버 예외 |
| 502 | E5020 | 외부 API 호출에 실패했습니다. | 카카오 API 등 외부 API 실패 |
