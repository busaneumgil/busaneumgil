# 📋 경로 북마크 API 명세

> **작성일:** 2026-04-12  
> **작성자:** 김응서  
> **최종 수정일:** 2026-04-28

---

## 1. API 목록

| 우선순위 | API | 설명 |
| --- | --- | --- |
| P1 | `GET /favorite-routes` | 경로 북마크 목록 조회 |
| P1 | `POST /favorite-routes` | 경로 북마크 저장 |
| P1 | `PATCH /favorite-routes/{favRouteId}` | 경로 북마크 수정 |
| P1 | `DELETE /favorite-routes/{favRouteId}` | 경로 북마크 삭제 |

> 경로 북마크 서버 API는 로그인 사용자의 서버 저장 데이터만 처리한다. 운영 기준 비로그인 경로 북마크 저장은 제공하지 않는다.

---

## 2. 경로 북마크 목록 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/favorite-routes` |
| 인증 | 필요 |
| 설명 | 로그인 사용자가 서버에 저장한 경로 북마크 목록을 조회한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |

#### Query Parameter

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| page | int | N | 페이지 번호 |
| size | int | N | 페이지 크기 |

#### Body

> 없음

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| content | array | N | 경로 북마크 목록 |
| content[].favRouteId | Long | N | 경로 북마크 ID |
| content[].routeName | string | N | 경로명 |
| content[].startLabel | string | N | 출발지명 |
| content[].endLabel | string | N | 도착지명 |
| content[].startPoint | object | N | 출발지 좌표 |
| content[].endPoint | object | N | 도착지 좌표 |
| content[].routeOption | string | N | 경로 옵션. `SHORTEST`, `SAFE` |
| page | int | N | 현재 페이지 번호 |
| size | int | N | 페이지 크기 |
| totalElements | Long | N | 전체 데이터 수 |
| totalPages | int | N | 전체 페이지 수 |
| hasNext | boolean | N | 다음 페이지 존재 여부 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "content": [
      {
        "favRouteId": 1,
        "routeName": "집에서 병원",
        "startLabel": "부산시민공원",
        "endLabel": "부산역",
        "startPoint": {
          "lat": 35.1686,
          "lng": 129.0576
        },
        "endPoint": {
          "lat": 35.1152,
          "lng": 129.0422
        },
        "routeOption": "SAFE"
      }
    ],
    "page": 0,
    "size": 10,
    "totalElements": 1,
    "totalPages": 1,
    "hasNext": false
  },
  "message": "정상 처리되었습니다."
}
```

#### 비고

- 목록 정렬은 최신 저장순을 기본으로 한다.
- `routeName`은 사용자가 직접 입력한 이름이 아니라 `startLabel`과 `endLabel`을 기준으로 서버가 자동 생성한 표시명이며, 최대 511자다.

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | C4000 | 잘못된 입력입니다. | page/size 형식 또는 범위 오류 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |

## 3. 경로 북마크 저장

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/favorite-routes` |
| 인증 | 필요 |
| 설명 | 로그인 사용자의 경로 북마크를 서버에 저장한다. 실제 edge 목록이 아니라 재탐색에 필요한 출발지/도착지/옵션을 저장한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |
| Content-Type | Y | `application/json` |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| startLabel | string | Y | 출발지명 |
| endLabel | string | Y | 도착지명 |
| startPoint | object | Y | 출발지 좌표 |
| startPoint.lat | number | Y | 위도 |
| startPoint.lng | number | Y | 경도 |
| endPoint | object | Y | 도착지 좌표 |
| endPoint.lat | number | Y | 위도 |
| endPoint.lng | number | Y | 경도 |
| routeOption | string | Y | 경로 옵션. `SHORTEST`, `SAFE` |

#### Request Example

```json
{
  "startLabel": "부산시민공원",
  "endLabel": "부산역",
  "startPoint": {
    "lat": 35.1686,
    "lng": 129.0576
  },
  "endPoint": {
    "lat": 35.1152,
    "lng": 129.0422
  },
  "routeOption": "SAFE"
}
```

### Response

- HTTP Status: `201 Created`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| favRouteId | Long | N | 경로 북마크 ID |

#### Success Example

```json
{
  "status": "S2010",
  "data": {
    "favRouteId": 1
  },
  "message": "생성되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | C4000 | 잘못된 입력입니다. | 필수값 누락 또는 좌표/경로 옵션 형식 오류 |
| 400 | FR4000 | 경로 북마크 요청값이 올바르지 않습니다. | 경로 북마크 생성 규칙 위반 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |

## 4. 경로 북마크 수정

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `PATCH` |
| URL | `/favorite-routes/{favRouteId}` |
| 인증 | 필요 |
| 설명 | 로그인 사용자의 서버 저장 경로 북마크를 수정한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |
| Content-Type | Y | `application/json` |

#### Path Variable

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| favRouteId | Long | Y | 경로 북마크 ID |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| startLabel | string | N | 출발지명 |
| endLabel | string | N | 도착지명 |
| startPoint | object | N | 출발지 좌표 |
| endPoint | object | N | 도착지 좌표 |
| routeOption | string | N | 경로 옵션. `SHORTEST`, `SAFE` |

#### Request Example

```json
{
  "routeOption": "SAFE"
}
```

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| favRouteId | Long | N | 경로 북마크 ID |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "favRouteId": 1
  },
  "message": "정상 처리되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | C4000 | 잘못된 입력입니다. | 요청 body, path variable, 좌표/경로 옵션 형식 오류 |
| 400 | FR4001 | 경로 북마크 수정 요청값이 올바르지 않습니다. | 수정 필드가 없거나 경로 북마크 수정 규칙 위반 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | FR4030 | 경로 북마크에 대한 권한이 없습니다. | 다른 사용자의 경로 북마크 수정 시도 |
| 404 | FR4040 | 경로 북마크를 찾을 수 없습니다. | 경로 북마크가 존재하지 않음 |

### 처리 규칙

- 저장/수정 시 실제 안내 경로의 edge 목록이나 경로 상세는 저장하지 않는다.
- 서버에는 나중에 다시 경로 탐색을 호출할 수 있는 출발지, 도착지, 경로 옵션만 저장한다.
- `routeName`은 `startLabel`과 `endLabel` 기준으로 자동 생성하며, 최대 511자다.
