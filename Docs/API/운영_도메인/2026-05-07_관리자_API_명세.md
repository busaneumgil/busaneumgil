## 1. API 목록

| 우선순위 | API | 설명 |
| --- | --- | --- |
| P1 | `GET /admin/me` | 관리자 principal 조회 |
| P1 | `GET /admin/areas` | 관리자 검수 구/동 목록 조회 |
| P1 | `GET /admin/road-network/segments` | 관리자 보행 네트워크 조회 |
| P1 | `POST /admin/road-network/edits/apply` | 관리자 보행 네트워크 편집 반영 |
| P1 | `GET /admin/places/facilities` | 관리자 편의시설 조회 |
| P1 | `GET /admin/places/{placeId}` | 관리자 장소 상세 조회 |
| P1 | `PATCH /admin/places/{placeId}` | 관리자 장소 기본 정보 수정 |
| P1 | `PUT /admin/places/{placeId}/accessibility-features` | 관리자 장소 접근성 속성 교체 |
| P1 | `GET /admin/hazard-reports` | 관리자 제보 목록 조회 |
| P1 | `GET /admin/hazard-reports/{reportId}` | 관리자 제보 상세 조회 |
| P1 | `PATCH /admin/hazard-reports/{reportId}/approve` | 제보 승인 |
| P1 | `PATCH /admin/hazard-reports/{reportId}/reject` | 제보 반려 |

> 관리자 API도 API 전용 서브도메인 기준으로 노출하므로 기본 path prefix로 `/api`를 붙이지 않는다.
> 관리자 기능은 로그인 사용자 중 `users.role=ADMIN`인 계정만 사용할 수 있다.
> 백엔드는 해당 사용자에게 Spring Security `ROLE_ADMIN` 권한을 부여하고 `/admin/**`를 `ADMIN` 권한으로 제한한다.
> 관리자 지도 화면은 CSV editor 서버를 호출하지 않고, 백엔드 RDB 조회 API만 사용한다.
> 구/동 selector와 보행 네트워크 필터를 사용하려면 행정동 GeoJSON을 `admin_areas`에 먼저 적재해야 한다.
> dev/prod 적재 스크립트는 각각 `scripts/db/load_admin_areas_dev.sh`, `scripts/db/load_admin_areas_prod.sh`를 사용한다.
> 편의시설 조회를 사용하려면 `places_erd.csv`, `place_accessibility_features_erd.csv`를 `scripts/db/load_places_dev.sh` 또는 `scripts/db/load_places_prod.sh`로 먼저 적재해야 한다.

## 2. 관리자 principal 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/admin/me` |
| 인증 | 필요 |
| 설명 | 현재 로그인한 관리자 principal과 permission 목록을 조회한다. |

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| userId | UUID | N | 사용자 ID |

| permissions | array | N | 관리자 permission 목록 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {

      "ADMIN_MAP_READ",

      "ADMIN_PLACE_WRITE",

      "HAZARD_REPORT_REVIEW"

  },
```

## 3. 관리자 검수 구/동 목록 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/admin/areas` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 관리자 보행 네트워크 검수 화면에서 사용할 구/동 목록을 조회한다. |

### 처리 규칙

- `admin_areas.gu`, `admin_areas.dong`에 값이 있는 행만 목록에 포함한다.
- `admin_areas`는 관리자 검수 화면의 구/동 selector와 보행 네트워크 공간 필터에 사용한다.
- `gu`, `dong`은 `road_segments` 컬럼이 아니다.
- `명지1동`, `명지2동`처럼 숫자 동이 있는 경우 기존 관리자 화면과 동일하게 `명지동` 형태의 묶음 선택지를 함께 제공할 수 있다.

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| areas | array | N | 구/동 목록 |
| areas[].gu | string | N | 구 |
| areas[].dong | string | N | 동 |

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | A4030 | 권한이 없습니다. | `users.role`이 `ADMIN`이 아님 |

## 4. 관리자 보행 네트워크 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/admin/road-network/segments` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 행정동 경계와 교차하는 DB `road_segments`를 관리자 지도 렌더링용 GeoJSON payload로 조회한다. |

### Request

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| gu | string | N | 구 필터. `dong`과 함께 있을 때 `admin_areas` 경계 기준으로 적용 |
| dong | string | N | 동 필터. `gu`와 함께 있을 때 `admin_areas` 경계 기준으로 적용. 숫자 동 묶음 선택지는 해당 숫자 동들을 함께 조회 |
| limit | int | N | 조회 개수. 기본값 `10000`, 허용 범위 `1`~`20000` |

### 처리 규칙

- `gu`, `dong`이 모두 있으면 `admin_areas.geom` 기준 500m buffer의 bounding box와 교차하는 `road_segments`를 조회한다.
- 이는 기존 CSV 관리자 서버가 행정동 GeoJSON에서 bbox를 계산해 segment를 필터링하던 방식을 DB 기반으로 옮긴 것이다.
- `gu` 또는 `dong`이 없으면 전체 `road_segments` 중 `limit`만큼 조회한다.

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| summary.segmentCount | long | N | 조건에 맞는 전체 segment 개수 |
| summary.visibleSegmentCount | int | N | 응답에 포함된 segment 개수 |
| bbox | array | Y | `[minLng, minLat, maxLng, maxLat]`. 조회 결과가 없으면 `null` |
| segments.type | string | N | `FeatureCollection` |
| segments.features[].geometry.type | string | N | `LineString` |
| segments.features[].properties.edgeId | Long | N | segment ID |
| segments.features[].properties.segmentType | string | N | `SIDE_LINE`, `CROSS_WALK` |

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | C4000 | 잘못된 입력입니다. | `limit`이 허용 범위를 벗어남 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | A4030 | 권한이 없습니다. | `users.role`이 `ADMIN`이 아님 |

## 5. 관리자 보행 네트워크 편집 반영

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/admin/road-network/edits/apply` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 관리자 화면의 로컬 draft를 DB `road_nodes`, `road_segments`, `segment_features`에 트랜잭션으로 반영한다. |

### 처리 규칙

- `add_segment`는 양 끝점 기준 1.5m 이내의 기존 `road_nodes`가 있으면 해당 node에 snap한다.
- 1.5m 이내 node가 없으면 새 `road_nodes`를 생성한다.
- 새 `road_segments.edge_id`, `road_nodes.vertex_id`, `segment_features.feature_id`는 DB sequence를 사용한다.
- 새 segment의 접근성 속성은 `source_features`와 공간 매칭해 `segment_features` 및 `road_segments` 집계 컬럼에 반영한다.
- `delete_segment`는 `segment_features` 삭제 후 `road_segments`를 삭제한다.
- `delete_node`는 해당 node에 연결된 segment까지 삭제 대상으로 포함한다.
- 반영 마지막에 더 이상 참조되지 않는 `road_nodes`를 정리한다.
- `source_features`는 원천 참조 테이블이므로 수정하지 않는다.

### Request

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| edits | array | Y | 반영할 draft 목록 |
| edits[].action | string | Y | `add_segment`, `delete_segment`, `delete_node` |
| edits[].segmentType | string | N | `add_segment`일 때 segment 유형. `SIDE_LINE`, `CROSS_WALK` |
| edits[].geom.type | string | N | `add_segment`일 때 `LineString` |
| edits[].geom.coordinates | array | N | `add_segment`일 때 `[lng, lat]` 좌표 배열 |
| edits[].edgeId | Long | N | `delete_segment` 대상 segment ID |
| edits[].vertexId | Long | N | `delete_node` 대상 node ID |
| edits[].reason | string | N | 관리자 화면에서 기록한 편집 사유 |

#### Request Example

```json
{
  "edits": [
    {
      "action": "add_segment",
      "segmentType": "SIDE_LINE",
      "geom": {
        "type": "LineString",
        "coordinates": [
          [128.9231, 35.1032],
          [128.9236, 35.1038]
        ]
      }
    },
    {
      "action": "delete_segment",
      "edgeId": 204582,
      "reason": "manual_polygon_delete"
    }
  ]
}
```

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| addedSegments | int | N | 추가된 segment 개수 |
| deletedSegments | int | N | 삭제된 segment 개수 |
| createdNodes | int | N | 새로 생성된 node 개수 |
| snappedNodes | int | N | 기존 node에 snap된 횟수 |
| removedOrphanNodes | int | N | 정리된 고아 node 개수 |
| createdSegmentFeatures | int | N | 생성된 `segment_features` 개수 |
| updatedSegmentAttributes | int | N | `source_features` 매칭으로 집계 컬럼이 갱신된 segment 개수 |
| addedEdgeIds | array | N | 추가된 segment ID 목록 |
| deletedEdgeIds | array | N | 실제 삭제된 segment ID 목록 |
| createdNodeIds | array | N | 생성된 node ID 목록 |
| snappedNodeIds | array | N | snap된 node ID 목록 |

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | C4000 | 잘못된 입력입니다. | action/좌표/ID가 올바르지 않음 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | A4030 | 권한이 없습니다. | `users.role`이 `ADMIN`이 아님 |

## 8. 관리자 장소 기본 정보 수정

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `PATCH` |
| URL | `/admin/places/{placeId}` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 관리자 페이지에서 장소명, 카테고리, 주소, 좌표, providerPlaceId를 수정한다. |

### Request Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| name | string | N | 장소명. `null`이면 기존 값을 유지 |
| category | string | N | 장소 카테고리. `null`이면 기존 값을 유지 |
| address | string | N | 주소. `null`이면 기존 값을 유지하고 빈 문자열이면 제거 |
| point.lat | number | N | 위도. `point`가 `null`이면 기존 좌표 유지 |
| point.lng | number | N | 경도. `point`가 `null`이면 기존 좌표 유지 |
| providerPlaceId | string | N | 외부 provider 장소 ID. `null`이면 기존 값을 유지하고 빈 문자열이면 제거 |

### 처리 규칙

- `providerPlaceId`는 `places.provider_place_id` unique 기준을 유지한다.
- 다른 장소에 이미 연결된 `providerPlaceId`로 수정하면 실패한다.
- 장소 수정은 접근성 속성을 변경하지 않는다.

### Response

- HTTP Status: `200 OK`
- 응답 형식은 `GET /admin/places/{placeId}`와 동일하다.

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | C4000 | 잘못된 입력입니다. | 요청 body 형식 또는 좌표 범위가 올바르지 않음 |
| 400 | PL4000 | 장소 조회 요청값이 올바르지 않습니다. | 장소명 누락, providerPlaceId 중복 등 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | A4030 | 권한이 없습니다. | `users.role`이 `ADMIN`이 아님 |
| 404 | PL4040 | 장소를 찾을 수 없습니다. | 장소가 존재하지 않음 |

## 9. 관리자 장소 접근성 속성 교체

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `PUT` |
| URL | `/admin/places/{placeId}/accessibility-features` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 관리자 페이지에서 해당 장소의 접근성 속성 목록을 요청 목록으로 전체 교체한다. |

### Request Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| features | array | Y | 교체할 접근성 속성 목록 |
| features[].featureType | string | Y | 접근성 속성 유형 |
| features[].isAvailable | boolean | Y | 제공 여부 |

### 처리 규칙

- 요청 목록이 해당 장소의 `place_accessibility_features` 전체 상태가 된다.
- 같은 `featureType`을 중복 요청할 수 없다.
- 접근성 속성을 모두 제거하려면 `features: []`를 보낸다.

### Response

- HTTP Status: `200 OK`
- 응답 형식은 `GET /admin/places/{placeId}`와 동일하다.

### Error

| HTTP Status | status | message | 발생 조건 |
