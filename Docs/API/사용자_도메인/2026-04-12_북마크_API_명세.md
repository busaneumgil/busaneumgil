# 📋 북마크 API 명세

> **작성일:** 2026-04-12  
> **작성자:** 김응서  
> **최종 수정일:** 2026-04-28

---

## 1. API 목록

| 우선순위 | API | 설명 |
| --- | --- | --- |
| P1 | `GET /bookmarks` | 저장한 장소 목록 조회 |
| P1 | `POST /bookmarks` | 장소 북마크 등록. 외부 검색 장소는 `places` 저장 후 북마크 |
| P1 | `DELETE /bookmarks/places/{placeId}` | 장소 북마크 해제 |

> 북마크 서버 API는 로그인 사용자의 서버 저장 데이터만 처리한다. 운영 기준 비로그인 북마크 저장은 제공하지 않는다.

## 2. 저장한 장소 목록 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/bookmarks` |
| 인증 | 필요 |
| 설명 | 로그인 사용자가 서버에 저장한 장소 북마크 목록을 조회한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |

#### Query Parameter

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| page | int | N | 페이지 번호 |
| size | int | N | 페이지 크기 |

#### Body

> 없음

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| content | array | N | 북마크 장소 목록 |
| content[].bookmarkId | Long | N | 북마크 ID |
| content[].placeId | Long | N | 장소 ID |
| content[].provider | string | Y | 장소 원천. `KAKAO`, `PUBLIC_DATA` |
| content[].providerPlaceId | string | Y | 카카오 장소 ID |
| content[].name | string | N | 장소명 |
| content[].category | string | N | 장소 카테고리. 장소 도메인의 `PlaceCategory`를 따른다. |
| content[].address | string | Y | 주소 |
| content[].point | object | N | 장소 좌표 |
| page | int | N | 현재 페이지 번호 |
| size | int | N | 페이지 크기 |
| totalElements | Long | N | 전체 데이터 수 |
| totalPages | int | N | 전체 페이지 수 |
| hasNext | boolean | N | 다음 페이지 존재 여부 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "content": [
      {
        "bookmarkId": 1,
        "placeId": 10,
        "provider": "KAKAO",
        "providerPlaceId": "123456789",
        "name": "부산시민공원",
        "category": "TOURIST_SPOT",
        "address": "부산광역시 부산진구 시민공원로 73",
        "point": {
          "lat": 35.1686,
          "lng": 129.0576
        }
      }
    ],
    "page": 0,
    "size": 10,
    "totalElements": 1,
    "totalPages": 1,
    "hasNext": false
  },
  "message": "정상 처리되었습니다."
}
```

#### 비고

- 목록 정렬은 최신 북마크순을 기본으로 한다.

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |

## 3. 장소 북마크 등록

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/bookmarks` |
| 인증 | 필요 |
| 설명 | 로그인 사용자의 장소를 서버 북마크로 등록한다. 내부 장소는 `placeId`로 등록하고, 외부 검색 장소는 `provider`, `providerPlaceId` 기준으로 `places`를 조회하거나 생성한 뒤 북마크한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |
| Content-Type | Y | `application/json` |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| placeId | Long | N | 내부 장소 ID. 값이 있으면 이 장소를 바로 북마크 |
| provider | string | N | 외부 장소 원천. `placeId`가 없을 때 필수. MVP는 `KAKAO` |
| providerPlaceId | string | N | 카카오 장소 ID. `placeId`가 없을 때 필수 |
| name | string | N | 장소명. `placeId`가 없을 때 필수 |
| category | string | N | 우리 서비스 장소 카테고리. `placeId`가 없을 때 필수. 장소 도메인의 `PlaceCategory`를 따른다. |
| sourceCategoryName | string | N | 카카오 `category_name` 등 원천 카테고리명 |
| address | string | N | 주소 |
| point | object | N | 장소 좌표. `placeId`가 없을 때 필수 |
| point.lat | double | N | 위도 |
| point.lng | double | N | 경도 |

#### Request Example

내부 장소 북마크:

```json
{
  "placeId": 10
}
```

외부 검색 장소 북마크:

```json
{
  "provider": "KAKAO",
  "providerPlaceId": "987654321",
  "name": "광안리해수욕장",
  "category": "TOURIST_SPOT",
  "address": "부산광역시 수영구 광안해변로 219",
  "point": {
    "lat": 35.1532,
    "lng": 129.1186
  }
}
```

### Response

- HTTP Status: `201 Created`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| bookmarkId | Long | N | 북마크 ID |
| placeId | Long | N | 장소 ID |
| provider | string | Y | 장소 원천 |
| providerPlaceId | string | Y | 카카오 장소 ID |
| createdPlace | boolean | N | 외부 장소 요청으로 `places`가 새로 생성되었는지 여부 |

#### Success Example

```json
{
  "status": "S2010",
  "data": {
    "bookmarkId": 1,
    "placeId": 10,
    "provider": "KAKAO",
    "providerPlaceId": "123456789",
    "createdPlace": false
  },
  "message": "생성되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | BM4000 | 북마크 요청값이 올바르지 않습니다. | `placeId`가 없고 외부 장소 저장에 필요한 `provider`, `providerPlaceId`, `name`, `category`, `point` 누락 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 404 | BM4040 | 장소를 찾을 수 없습니다. | `placeId`로 요청한 내부 장소가 존재하지 않음 |
| 409 | BM4090 | 이미 북마크한 장소입니다. | 이미 북마크한 장소 |

### 처리 규칙

- `placeId`가 있으면 내부 `places.placeId`를 기준으로 북마크한다.
- `placeId`가 없고 `provider`, `providerPlaceId`가 있으면 `places.provider`, `places.providerPlaceId` 조합으로 기존 장소를 조회한다.
- 조회되지 않으면 요청의 `provider`, `providerPlaceId`, `name`, `category`, `sourceCategoryName`, `address`, `point`로 `places`를 먼저 생성하고, 생성된 `placeId`로 북마크한다.
- 서버 저장 시 `bookmarks`에는 최종적으로 UUID 기반 `userId`, `placeId`만 저장한다.
- `placeId`는 우리 DB의 내부 자동 증가 ID다. 카카오 장소 ID를 내부 PK로 사용하지 않는다.
- 카카오 카테고리는 `sourceCategoryName`으로만 보존하고, `category`에는 우리 서비스 장소 카테고리를 저장한다.

## 4. 장소 북마크 해제

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `DELETE` |
| URL | `/bookmarks/places/{placeId}` |
| 인증 | 필요 |
| 설명 | 로그인 사용자의 서버 북마크를 장소 ID 기준으로 해제한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |

#### Path Variable

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| placeId | Long | Y | 북마크 해제할 장소 ID |

#### Body

> 없음

### Response

- HTTP Status: `204 No Content`
- 응답 Body 없음

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | BM4001 | 북마크 해제 요청값이 올바르지 않습니다. | `placeId` 형식 오류 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 404 | BM4041 | 북마크 내역을 찾을 수 없습니다. | 북마크 내역이 존재하지 않음 |
