## 1. API 목록

| --- | --- | --- |
| P1 | `GET /admin/me` | 관리자 principal 조회 |

| P1 | `GET /admin/road-network/segments` | 관리자 보행 네트워크 조회 |

| P1 | `GET /admin/places/{placeId}` | 관리자 장소 상세 조회 |
| P1 | `PATCH /admin/places/{placeId}` | 관리자 장소 기본 정보 수정 |
| P1 | `PUT /admin/places/{placeId}/accessibility-features` | 관리자 장소 접근성 속성 교체 |
| P1 | `GET /admin/hazard-reports` | 관리자 제보 목록 조회 |
| P1 | `GET /admin/hazard-reports/{reportId}` | 관리자 제보 상세 조회 |
| P1 | `PATCH /admin/hazard-reports/{reportId}/approve` | 제보 승인 |
| P1 | `PATCH /admin/hazard-reports/{reportId}/reject` | 제보 반려 |

> 관리자 API도 API 전용 서브도메인 기준으로 노출하므로 기본 path prefix로 `/api`를 붙이지 않는다.
> 관리자 기능은 로그인 사용자 중 `users.role=ADMIN`인 계정만 사용할 수 있다.
> 백엔드는 해당 사용자에게 Spring Security `ROLE_ADMIN` 권한을 부여하고 `/admin/**`를 `ADMIN` 권한으로 제한한다.
> 관리자 지도 화면은 CSV editor 서버를 호출하지 않고, 백엔드 RDB 조회 API만 사용한다.
> 구/동 selector와 보행 네트워크 필터를 사용하려면 행정동 GeoJSON을 `admin_areas`에 먼저 적재해야 한다.
> 보행 네트워크와 장소/접근성 수정 API는 `admin_area_assignments`에 지정된 담당 구/동만 수정할 수 있다.
> dev/prod 적재 스크립트는 각각 `scripts/db/load_admin_areas_dev.sh`, `scripts/db/load_admin_areas_prod.sh`를 사용한다.
> 편의시설 조회를 사용하려면 `places_erd.csv`, `place_accessibility_features_erd.csv`를 `scripts/db/load_places_dev.sh` 또는 `scripts/db/load_places_prod.sh`로 먼저 적재해야 한다.

## 2. 관리자 principal 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/admin/me` |
| 인증 | 필요 |
| 설명 | 현재 로그인한 관리자 principal과 permission 목록을 조회한다. |

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| userId | UUID | N | 사용자 ID |
| role | string | N | 관리자 권한. `ADMIN` |
| permissions | array | N | 관리자 permission 목록 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "userId": "019df09d-ce19-78f0-b331-4ec38ae99ce5",
    "role": "ADMIN",
    "permissions": [
      "ADMIN_MAP_READ",
      "ADMIN_USER_READ",
      "ADMIN_USER_WRITE",
      "ADMIN_AREA_ASSIGNMENT_READ",
      "ADMIN_AREA_ASSIGNMENT_WRITE",
      "ADMIN_PLACE_READ",
      "ADMIN_PLACE_WRITE",
      "HAZARD_REPORT_READ",
      "HAZARD_REPORT_REVIEW"
    ]
  },
  "message": "정상 처리되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | A4030 | 권한이 없습니다. | `users.role`이 `ADMIN`이 아님 |

## 2-2. 관리자 사용자 권한 수정

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `PATCH` |
| URL | `/admin/users/{userId}/role` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 사용자 role을 `USER` 또는 `ADMIN`으로 변경한다. |

### 처리 규칙

- 자기 자신의 관리자 권한을 해제할 수 없다.
- 신규 가입자는 기본 `USER`이며, 이 API로 `ADMIN` 승격 후 관리자 화면에 접근할 수 있다.

### Request Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| role | string | Y | `USER`, `ADMIN` |

### Response

- HTTP Status: `200 OK`
- 응답 형식은 `GET /admin/users`의 `users[]` 항목과 동일하다.

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | C4000 | 잘못된 입력입니다. | role 누락/오류, 자기 자신 권한 해제 시도 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 403 | A4030 | 권한이 없습니다. | `users.role`이 `ADMIN`이 아님 |
| 404 | U4040 | 사용자를 찾을 수 없습니다. | 존재하지 않는 userId |

| 인증 | 필요, 관리자 권한 필요 |

### 처리 규칙

- `admin_areas.gu`, `admin_areas.dong`에 값이 있는 행만 목록에 포함한다.

### Response

## 4. 관리자 보행 네트워크 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/admin/road-network/segments` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 행정동 경계를 100m 확장한 polygon과 교차하는 DB `road_segments`를 관리자 지도 렌더링용 GeoJSON payload로 조회한다. |

### Request

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| gu | string | N | 구 필터. `dong`과 함께 있을 때 `admin_areas` 경계 100m buffer polygon 기준으로 적용 |
| dong | string | N | 동 필터. `gu`와 함께 있을 때 `admin_areas` 경계 100m buffer polygon 기준으로 적용. 숫자 동 묶음 선택지는 해당 숫자 동들을 함께 조회 |
| limit | int | N | 조회 개수. 기본값 `10000`, 허용 범위 `1`~`20000` |

### 처리 규칙

- `gu`, `dong`이 모두 있으면 `admin_areas.geom`을 100m 확장한 polygon과 교차하는 `road_segments`를 조회한다.
- 행정동 원본 polygon을 그대로 쓰지 않고 100m buffer를 두는 이유는 경계 근처 연결 상태까지 함께 검수하기 위함이다.
- `ST_Envelope` 기반 bounding box는 사용하지 않는다.
- `gu` 또는 `dong`이 없으면 전체 `road_segments` 중 `limit`만큼 조회한다.

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| summary.segmentCount | long | N | 조건에 맞는 전체 segment 개수 |
| summary.visibleSegmentCount | int | N | 응답에 포함된 segment 개수 |
| bbox | array | Y | `[minLng, minLat, maxLng, maxLat]`. 조회 결과가 없으면 `null` |
| segments.type | string | N | `FeatureCollection` |
| segments.features[].geometry.type | string | N | `LineString` |
| segments.features[].properties.edgeId | Long | N | segment ID |
| segments.features[].properties.fromNodeId | Long | N | 시작 node ID |
| segments.features[].properties.toNodeId | Long | N | 종료 node ID |
| segments.features[].properties.segmentType | string | N | `SIDE_LINE`, `CROSS_WALK` |
| segments.features[].properties.lengthMeter | decimal | N | segment 길이. meter 단위 |
| segments.features[].properties.walkAccess | string | Y | 통행 가능 상태 |
| segments.features[].properties.brailleBlockState | string | Y | 점자블록 상태 |
| segments.features[].properties.audioSignalState | string | Y | 음향신호기 상태 |
| segments.features[].properties.widthState | string | Y | 보도 폭 상태 |
| segments.features[].properties.surfaceState | string | Y | 노면 상태 |
| segments.features[].properties.stairsState | string | Y | 계단 상태 |
| segments.features[].properties.signalState | string | Y | 신호등 상태 |

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | C4000 | 잘못된 입력입니다. | `limit`이 허용 범위를 벗어남 |

## 5. 관리자 보행 네트워크 편집 반영

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/admin/road-network/edits/apply` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 관리자 화면의 로컬 draft를 DB `road_nodes`, `road_segments`, `segment_features`에 트랜잭션으로 반영한다. |

### 처리 규칙

- `add_segment`는 양 끝점 기준 1.0m 이내의 기존 `road_nodes`가 있으면 해당 node에 snap한다.
- 1.0m 이내 node가 없으면 새 `road_nodes`를 생성한다.
- 새 `road_segments.edge_id`, `road_nodes.vertex_id`, `segment_features.feature_id`는 DB sequence를 사용한다.
- 새 segment의 접근성 속성은 `source_features`와 공간 매칭해 `segment_features` 및 `road_segments` 집계 컬럼에 반영한다.
- add 작업은 요청 edit을 DB 임시 테이블에 적재한 뒤 node snap, node 생성, segment 생성, `source_features` 매칭을 set-based SQL로 처리한다.
- `delete_segment`는 `segment_features` 삭제 후 `road_segments`를 삭제한다.
- `delete_node`는 해당 node에 연결된 segment까지 삭제 대상으로 포함한다.
- 반영 마지막에 더 이상 참조되지 않는 `road_nodes`를 정리한다.
- `source_features`는 원천 참조 테이블이므로 수정하지 않는다.
- 요청한 관리자가 담당자로 지정된 구/동 안의 segment만 추가/삭제할 수 있다.

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| gu | string | Y | 담당 구 |
| dong | string | Y | 담당 동 |
| edits | array | Y | 반영할 draft 목록 |
| edits[].action | string | Y | `add_segment`, `delete_segment`, `delete_node` |
| edits[].segmentType | string | N | `add_segment`일 때 segment 유형. `SIDE_LINE`, `CROSS_WALK` |
| edits[].geom.type | string | N | `add_segment`일 때 `LineString` |
| edits[].geom.coordinates | array | N | `add_segment`일 때 `[lng, lat]` 좌표 배열 |
| edits[].edgeId | Long | N | `delete_segment` 대상 segment ID |
| edits[].vertexId | Long | N | `delete_node` 대상 node ID |
| edits[].reason | string | N | 관리자 화면에서 기록한 편집 사유 |

## 6. 관리자 보행 네트워크 편집 반영 작업

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/admin/road-network/edits/jobs` |
| 인증 | 필요, 관리자 권한 필요 |
| 설명 | 관리자 화면의 대량 draft를 비동기 반영 작업으로 등록한다. |

### 처리 규칙

- `POST /admin/road-network/edits/apply`는 소량 수동 편집을 즉시 반영하는 동기 API다.
- `POST /admin/road-network/edits/jobs`는 최대 1000개 edit을 작업으로 등록하고 `jobId`를 반환한다.
- 작업은 서버 내부 executor에서 실행되며, 실제 DB 반영 로직은 `/apply`와 같은 bulk 트랜잭션 처리 규칙을 사용한다.
- ADMIN은 `GET /admin/road-network/edits/jobs/{jobId}`를 polling해 `SUCCEEDED` 또는 `FAILED`가 될 때까지 상태를 확인한다.
- 작업 결과는 성공 시 `result`에 포함된다.
- 서버 재시작 시 아직 완료되지 않은 `PENDING`/`RUNNING` 작업은 실제 worker 상태를 복구할 수 없으므로 `FAILED`로 닫는다.

### Request

`POST /admin/road-network/edits/apply`와 동일하다.

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| jobId | Long | N | 편집 반영 작업 ID |
| status | string | N | `PENDING`, `RUNNING`, `SUCCEEDED`, `FAILED` |
| totalEdits | int | N | 요청 edit 개수 |
| processedEdits | int | N | 반영 완료된 edit 개수. 성공 시 `totalEdits`와 같다 |
| message | string | N | 현재 작업 상태 메시지 |
| result | object | Y | 성공 시 `/apply` 응답과 같은 반영 결과 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "jobId": 15,
    "status": "RUNNING",
    "totalEdits": 1000,
    "processedEdits": 0,
    "message": "편집 반영 중입니다.",
    "result": null
  },
  "message": "정상 처리되었습니다."
}
```
