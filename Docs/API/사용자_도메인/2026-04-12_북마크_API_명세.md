## 1. API 목록

| 우선순위 | API | 설명 |
| --- | --- | --- |
| P1 | `GET /bookmarks` | 저장한 장소 목록 조회 |
| P1 | `POST /bookmarks` | 장소 북마크 등록 |
| P1 | `DELETE /bookmarks/places/{placeId}` | 장소 북마크 해제 |

---

## 2. 저장한 장소 목록 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/bookmarks` |
| 인증 | 필요 |
| 설명 | 현재 사용자가 저장한 장소 목록을 조회한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |

#### Query Parameter

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| page | int | N | 페이지 번호 |
| size | int | N | 페이지 크기 |

#### Body

> 없음

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| content | array | N | 북마크 장소 목록 |
| content[].bookmarkId | Long | N | 북마크 ID |
| content[].placeId | Long | N | 장소 ID |
| content[].name | string | N | 장소명 |
| content[].category | string | N | 장소 카테고리 |
| content[].address | string | Y | 주소 |
| content[].point | object | N | 장소 좌표 |

---

## 3. 장소 북마크 등록

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/bookmarks` |
| 인증 | 필요 |
| 설명 | 장소를 북마크로 등록한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |
| Content-Type | Y | `application/json` |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| placeId | Long | Y | 북마크할 장소 ID |

### Response

- HTTP Status: `201 Created`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| bookmarkId | Long | N | 북마크 ID |
| placeId | Long | N | 장소 ID |

---

#### Body

> 없음

### Response

- HTTP Status: `204 No Content`
- `data = null`
