# 구현 결과 리뷰 기록

이 폴더는 경로/GraphHopper 관련 구현이 끝난 뒤, 커밋 단위 결과를 사람이 읽기 쉽게 남기는 로컬 리뷰 로그다.

작성 규칙:

- 구현 커밋마다 `YYYY-MM-DD_{이슈번호}_{요약}_review.md` 형식으로 작성한다.
- 문서에는 구현 범위, 변경 파일, 검증 결과, 남은 주의사항을 포함한다.
- `.ai/LOCAL/` 하위 문서이므로 git 커밋 대상에 포함하지 않는다.
- 공유가 필요한 결정이나 운영 기준은 이 폴더에만 남기지 말고 `Docs/`, `.ai/DECISIONS/`, `.ai/MEMORY/` 중 적절한 공유 문서로 승격한다.
