### SCR-001 온보딩 – 장애유형 선택

| 항목 | 내용 |
|------|------|
| **화면 ID** | SCR-001 |
| **화면명** | 온보딩 – 장애유형 선택 |
| **관련 기능** | 0-2 |
| **접근 경로** | 앱 최초 설치 후 자동 표시 / SCR-015 설정 메뉴 |
| **화면 설명** | 앱 최초 설치 후 가장 먼저 표시되는 초기 설정 화면. 사용자가 시각장애인인지 보행약자인지를 먼저 선택받아, 이후 모든 화면에서 즉시 맞춤화된 UI(글자 크기, 대비, TTS 음성 안내 등)를 적용하기 위한 핵심 기준값으로 활용한다. 이 화면에서 선택한 유형에 따라 SCR-002부터 UI가 분기된다. 이 화면 이후 장애등급 선택, 위치기반 정보 동의, 로그인 화면으로 순차 진행한다. |

**컴포넌트**

| 컴포넌트명 | 타입 | 설명 | 비고 |
|-----------|------|------|------|
| 진행 표시기 | ProgressIndicator | 온보딩 단계 표시 (1/3) | 초기 진입 단계 안내 |
| 안내 문구 | Text | "어떤 도움이 필요하신가요?" 대제목 | 첫 화면 핵심 질문, 큰 폰트 |
| 보조 설명 문구 | Text | 선택한 유형에 따라 앱 화면과 안내 방식이 맞춤 설정된다는 안내 | 쉬운 문장, 짧은 설명 |
| 시각장애 선택 카드 | SelectCard | 시각장애 유형 선택 버튼 (아이콘 + 설명) | 선택 시 시인성/음성 중심 UI로 즉시 전환 |
| 보행약자 선택 카드 | SelectCard | 보행약자 유형 선택 버튼 (아이콘 + 설명) | 선택 시 이동 지원 중심 UI 적용 |
| 건너뛰기 버튼 | TextButton | 선택 없이 다음 단계로 진행 | 기본 UI 모드로 진행, 추후 설정 메뉴에서 변경 가능 |
| 다음 버튼 | Button | 선택 내용을 저장하고 장애등급 선택 화면으로 이동 | 카드 선택 시 활성화 |

**액션 / 이벤트**

| 액션/이벤트 | 조건 | 이동/결과 | 설명 |
|------------|------|----------|------|
| 시각장애 카드 선택 | - | 카드 선택 상태 활성화 + 다음 버튼 활성화 | 이후 모든 화면에 시각 지원 중심 UI 즉시 적용 |
| 보행약자 카드 선택 | - | 카드 선택 상태 활성화 + 다음 버튼 활성화 | 이후 모든 화면에 이동 지원 중심 UI 즉시 적용 |
| 다음 버튼 탭 | 카드 선택 완료 | SCR-002 (온보딩 – 장애등급 선택) | 선택된 장애유형 저장 후 장애등급 선택 화면으로 이동 |
| 건너뛰기 탭 | - | SCR-002 (온보딩 – 장애등급 선택) | 기본 UI 모드 유지, 추후 설정에서 변경 가능 |

**공통 접근성 고려사항**

- 첫 화면인 만큼 장애유형 선택 즉시 해당 UI 모드(TTS, 고대비 등)를 화면에 바로 반영해 사용자가 선택 결과를 즉각 체감할 수 있도록 한다.
- 선택 카드는 색상뿐 아니라 텍스트와 음성 피드백으로 상태를 함께 전달한다.
- TalkBack과 호환되도록 각 선택 카드와 버튼에 접근성 라벨을 제공한다.

### SCR-002 온보딩 – 장애등급 선택

| 항목 | 내용 |
|------|------|
| **화면 ID** | SCR-002 |
| **화면명** | 온보딩 – 장애등급 선택 |
| **관련 기능** | 0-2 |
| **접근 경로** | SCR-001 선택 완료 후 자동 이동 |
| **화면 설명** | 장애유형 선택 직후 표시되는 화면. SCR-001에서 선택한 장애유형에 따라 이미 맞춤화된 UI(TTS, 고대비 등)가 적용된 상태에서 장애 등급 또는 필요한 지원 수준을 추가로 선택받아 글자 크기, 안내 강도 등 세부 접근성 수준을 조정하기 위한 기준값으로 활용한다. |

**컴포넌트**

| 컴포넌트명 | 타입 | 설명 | 비고 |
|-----------|------|------|------|
| 진행 표시기 | ProgressIndicator | 온보딩 단계 표시 (2/3) | 현재 초기 설정 진행 단계 안내 |
| 음성 안내 버튼 | IconButton | 현재 화면 설명과 선택 방법을 TTS로 재생/일시정지 | SCR-001에서 시각장애 선택 시 우선 노출 |
| 안내 문구 | Text | "장애 등급을 선택해주세요" 대제목 | 큰 폰트, 고대비 적용 |
| 보조 설명 문구 | Text | 앱의 안내 강도와 가독성을 세밀하게 조정하기 위한 추가 설정 안내 | 쉬운 문장, 짧은 설명 |
| 등급 선택 리스트 | RadioList | 장애 등급 옵션 목록 (1~6급 또는 해당없음) | 큰 터치 영역, 접근성 라벨 제공 |
| 건너뛰기 버튼 | TextButton | 선택 없이 다음 단계로 진행 | 기본 안내 강도로 진행 |
| 다음 버튼 | Button | 위치정보 이용약관 동의 화면으로 이동 | 등급 선택 시 활성화 |

**액션 / 이벤트**

| 액션/이벤트 | 조건 | 이동/결과 | 설명 |
|------------|------|----------|------|
| 음성 안내 버튼 탭 | 시각장애 모드 활성화 상태 | 현재 화면 안내 및 조작 방법 음성 재생/일시정지 | 시각 지원 사용자용 |
| 등급 항목 선택 | - | 선택 항목 하이라이트 + 다음 버튼 활성화 | 세부 접근성 수준 저장 |
| 다음 버튼 탭 | 등급 선택 완료 | SCR-003 (위치정보 이용약관 동의) | 선택된 등급 기준으로 다음 화면 구성 |
| 건너뛰기 탭 | - | SCR-003 (위치정보 이용약관 동의) | 기본 안내 강도 유지 후 다음 단계 진행 |

**접근성 고려사항**

- SCR-001에서 시각장애를 선택한 경우 이 화면 진입 시 TTS가 자동으로 안내를 시작한다.
- 등급 선택 리스트와 버튼은 최소 60x60pt 이상의 터치 영역을 확보한다.
- TalkBack 포커스 순서는 안내 문구 → 보조 설명 → 등급 선택 리스트 → 주요 버튼 순으로 구성한다.
