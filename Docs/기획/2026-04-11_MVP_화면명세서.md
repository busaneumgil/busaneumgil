## 3. 화면 상세 명세

### SCR-001 온보딩 - 장애유형 선택

| 항목 | 내용 |
|------|------|
| **화면 ID** | SCR-001 |
| **관련 기능** | 0-2 |
| **접근 경로** | 앱 최초 설치 후 자동 표시 |
| **화면 설명** | 사용자가 시각장애인인지 보행약자인지를 먼저 선택해 이후 화면의 기본 UI 모드를 결정하는 첫 화면. |

**컴포넌트**

| 컴포넌트명 | 타입 | 설명 |
|-----------|------|------|
| 진행 표시기 | ProgressIndicator | 온보딩 단계 표시 (1/3) |
| 안내 문구 | Text | "어떤 도움이 필요하신가요?" 대제목 |
| 보조 설명 문구 | Text | 선택에 따라 앱 화면과 안내 방식이 달라짐을 설명 |
| 시각장애 선택 카드 | SelectCard | 시각 지원 중심 UI 선택 |
| 보행약자 선택 카드 | SelectCard | 이동 지원 중심 UI 선택 |
| 건너뛰기 버튼 | TextButton | 기본 UI 모드로 다음 단계 진행 |
| 다음 버튼 | Button | SCR-002로 이동 |

**액션 / 이벤트**

| 액션/이벤트 | 조건 | 이동/결과 |
|------------|------|----------|
| 시각장애 카드 선택 | - | 카드 선택 상태 활성화 + 다음 버튼 활성화 |
| 보행약자 카드 선택 | - | 카드 선택 상태 활성화 + 다음 버튼 활성화 |
| 다음 버튼 탭 | 카드 선택 완료 | SCR-002 |
| 건너뛰기 탭 | - | SCR-002 |
