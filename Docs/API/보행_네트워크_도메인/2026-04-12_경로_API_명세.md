## 2. 경로 탐색

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/routes/search` |
| 인증 | 불필요 |
| 설명 | 출발지와 도착지를 기준으로 최단 경로와 안전 경로를 탐색한다. 경로 구간 정보, 위험도 정보, TTS 안내 문구를 응답에 포함한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Content-Type | Y | `application/json` |

#### Query Parameter

> 없음

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| startPoint | object | Y | 출발지 좌표 |
| startPoint.lat | number | Y | 출발지 위도 |
| startPoint.lng | number | Y | 출발지 경도 |
| endPoint | object | Y | 도착지 좌표 |
| endPoint.lat | number | Y | 도착지 위도 |
| endPoint.lng | number | Y | 도착지 경도 |
| destinationPlaceId | long | N | 내부 장소 ID. 있으면 목적지 scope 판단에 사용 |
| routeOptions | array | N | 요청할 경로 옵션 목록. 없으면 `SAFE`, `SHORTEST` 둘 다 반환 |

#### Request Example

```json
{
  "startPoint": {
    "lat": 35.1796,
    "lng": 129.0756
  },
  "endPoint": {
    "lat": 35.1577,
    "lng": 129.0590
  },
  "destinationPlaceId": 1024,
  "routeOptions": ["SAFE", "SHORTEST"]
}
```

### Response

#### Success

- HTTP Status: `200 OK`

#### Data Fields

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| routes | array | N | 탐색된 경로 목록 |
| routes[].routeOption | string | N | 경로 옵션. `SAFE`, `SHORTEST` |
| routes[].title | string | N | 경로 표시명 |
| routes[].distanceMeter | number | N | 총 거리 |
| routes[].estimatedTimeMinute | int | N | 예상 소요 시간 |
| routes[].riskLevel | string | N | 전체 경로 위험도. `LOW`, `MEDIUM`, `HIGH` |
| routes[].warningLabels | array | N | 전체 경로 위험 요약 라벨. 예: `STAIRS`, `HIGH_SLOPE`, `NARROW_WIDTH` |
| routes[].usedConditionalStairs | boolean | N | 목적지 조건부 계단 사용 여부 |
| routes[].segments | array | N | 경로 구간 목록 |
| routes[].segments[].sequence | int | N | 구간 순서 |
| routes[].segments[].geometry | string | N | 구간 선형 좌표 |
| routes[].segments[].distanceMeter | number | N | 구간 거리 |
| routes[].segments[].hasStairs | boolean | N | 계단 여부 |
| routes[].segments[].hasCurbGap | boolean | N | 단차 여부 |
| routes[].segments[].hasCrosswalk | boolean | N | 횡단보도 포함 여부 |
| routes[].segments[].hasSignal | boolean | N | 신호등 여부 |
| routes[].segments[].hasAudioSignal | boolean | N | 음향신호기 여부 |
| routes[].segments[].hasBrailleBlock | boolean | N | 점자블록 여부 |
| routes[].segments[].slopePercent | number | Y | 구간 대표 경사도(%) |
| routes[].segments[].widthState | string | Y | 폭 상태. `ADEQUATE_150`, `ADEQUATE_120`, `NARROW`, `UNKNOWN` |
| routes[].segments[].riskLevel | string | N | 구간 위험도 |
| routes[].segments[].warningLabels | array | N | 구간 위험 라벨 목록 |
| routes[].segments[].guidanceMessage | string | N | TTS 안내 문구 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "routes": [
      {
        "routeOption": "SAFE",
        "title": "안전 경로",
        "distanceMeter": 950,
        "estimatedTimeMinute": 16,
        "riskLevel": "LOW",
        "warningLabels": ["CROSSWALK"],
        "usedConditionalStairs": false,
        "segments": [
          {
            "sequence": 1,
            "geometry": "LINESTRING(129.0756 35.1796, 129.0760 35.1799)",
            "distanceMeter": 120,
            "hasStairs": false,
            "hasCurbGap": false,
            "hasCrosswalk": true,
            "hasSignal": true,
            "hasAudioSignal": true,
            "hasBrailleBlock": true,
            "slopePercent": 2.4,
            "widthState": "ADEQUATE_150",
            "riskLevel": "LOW",
            "warningLabels": ["CROSSWALK"],
            "guidanceMessage": "전방 횡단보도를 건넌 뒤 직진하세요."
          }
        ]
      }
    ]
  },
  "message": "정상 처리되었습니다."
}
```

### 비고

- `routeOptions`가 없으면 기본값으로 `["SAFE", "SHORTEST"]`를 적용한다.
- `routeOptions`가 `["SAFE"]`면 안전 경로만 반환한다.
- `routeOptions`가 `["SHORTEST"]`면 최단 경로만 반환한다.
- `destinationPlaceId`가 있으면 백엔드는 장소 scope를 해석해 목적지 조건부 계단을 조건부로 열 수 있다.
- `destinationPlaceId`가 없으면 기본적으로 `PUBLIC_DEFAULT` 계단만 사용한다.
- 경로 상세/구간 조회와 TTS 안내 문구는 별도 API로 분리하지 않고 이 응답의 `segments`에 포함한다.
- `warningLabels`, `usedConditionalStairs`, `slopePercent`, `widthState`는 기존 `road_segments`와 `segment_features`를 조합해 계산한 파생 응답값으로 본다.

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | RT4000 | 경로 요청값이 올바르지 않습니다. | 출발지/도착지 좌표 누락 또는 `routeOptions` 값 오류 |
| 404 | RT4040 | 탐색 가능한 경로가 없습니다. | 탐색 가능한 경로가 없음 |
| 500 | RT5000 | 경로 탐색 중 오류가 발생했습니다. | 경로 탐색 처리 중 서버 예외 |

## 3. 경로 별점 평가 저장

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/route-ratings` |
| 인증 | 필요 |
| 설명 | 도착 직후 사용자가 방금 안내받은 경로에 남긴 별점을 저장한다. 저장한 경로에 대한 평가가 아니며 의견 텍스트는 저장하지 않는다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |
| Content-Type | Y | `application/json` |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| routeOption | string | Y | 평가 대상 경로 옵션. `SAFE`, `SHORTEST` |
| score | int | Y | 별점. 1~5 |
| startPoint | object | Y | 안내받은 경로의 출발지 좌표 |
| startPoint.lat | number | Y | 위도 |
| startPoint.lng | number | Y | 경도 |
| endPoint | object | Y | 안내받은 경로의 도착지 좌표 |
| endPoint.lat | number | Y | 위도 |
| endPoint.lng | number | Y | 경도 |

#### Request Example

```json
{
  "routeOption": "SAFE",
  "score": 5,
  "startPoint": {
    "lat": 35.1686,
    "lng": 129.0576
  },
  "endPoint": {
    "lat": 35.1152,
    "lng": 129.0422
  }
}
```

### Response

- HTTP Status: `201 Created`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| ratingId | Long | N | 저장된 경로 평가 ID |

#### Success Example

```json
{
  "status": "S2010",
  "data": {
    "ratingId": 1
  },
  "message": "생성되었습니다."
}
```

### 비고

- 평가는 `ARR-02` 도착 직후 평가 모달에서 생성한다.
- 별점 외 의견 텍스트는 저장하지 않는다.
- 평가 대상은 `favorite_routes`가 아니라 방금 안내받은 경로다.
- 평가 생성 시각은 서버의 공통 `createdAt` 감사 컬럼으로 관리한다.

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | RR4000 | 경로 평가 요청값이 올바르지 않습니다. | `routeOption`, `score`, 좌표 형식 오류 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 500 | RR5000 | 경로 평가 저장 중 오류가 발생했습니다. | 경로 평가 저장 중 서버 예외 |

## 4. 경로 이탈 재탐색

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P2 |
| Method | `POST` |
| URL | `/routes/reroute` |
| 인증 | 불필요 |
| 설명 | 사용자가 기존 안내 경로를 이탈했을 때 현재 위치 기준으로 경로를 재탐색한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Content-Type | Y | `application/json` |

#### Query Parameter

> 없음

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| currentPoint | object | Y | 현재 위치 좌표 |
| currentPoint.lat | number | Y | 현재 위도 |
| currentPoint.lng | number | Y | 현재 경도 |
| endPoint | object | Y | 도착지 좌표 |
| endPoint.lat | number | Y | 도착지 위도 |
| endPoint.lng | number | Y | 도착지 경도 |
| destinationPlaceId | long | N | 내부 장소 ID. 최초 탐색과 동일한 scope 판단에 사용 |
| routeOption | string | Y | 기존 경로 옵션. `SAFE`, `SHORTEST` |

#### Request Example

```json
{
  "currentPoint": {
    "lat": 35.1796,
    "lng": 129.0756
  },
  "endPoint": {
    "lat": 35.1577,
    "lng": 129.0590
  },
  "destinationPlaceId": 1024,
  "routeOption": "SAFE"
}
```

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| routeOption | string | N | 경로 옵션 |
| distanceMeter | number | N | 총 거리 |
| estimatedTimeMinute | int | N | 예상 소요 시간 |
| riskLevel | string | N | 전체 경로 위험도 |
| warningLabels | array | N | 전체 경로 위험 요약 라벨 |
| usedConditionalStairs | boolean | N | 목적지 조건부 계단 사용 여부 |
| segments | array | N | 재탐색된 경로 구간 목록 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "routeOption": "SAFE",
    "distanceMeter": 720,
    "estimatedTimeMinute": 11,
    "riskLevel": "LOW",
    "warningLabels": ["CROSSWALK"],
    "usedConditionalStairs": false,
    "segments": [
      {
        "sequence": 1,
        "geometry": "LINESTRING(129.0756 35.1796, 129.0760 35.1799)",
        "distanceMeter": 120,
        "hasStairs": false,
        "hasCurbGap": false,
        "hasCrosswalk": true,
        "hasSignal": true,
        "hasAudioSignal": true,
        "hasBrailleBlock": true,
        "slopePercent": 2.4,
        "widthState": "ADEQUATE_150",
        "riskLevel": "LOW",
        "warningLabels": ["CROSSWALK"],
        "guidanceMessage": "전방 횡단보도를 건넌 뒤 직진하세요."
      }
    ]
  },
  "message": "정상 처리되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | RT4001 | 재탐색 요청값이 올바르지 않습니다. | 현재 위치/도착지 좌표 누락 또는 `routeOption` 값 오류 |
| 404 | RT4041 | 재탐색 가능한 경로가 없습니다. | 재탐색 가능한 경로가 없음 |
| 500 | RT5000 | 경로 탐색 중 오류가 발생했습니다. | 경로 재탐색 처리 중 서버 예외 |
