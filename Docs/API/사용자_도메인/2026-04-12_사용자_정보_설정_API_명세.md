# 📋 사용자 정보/설정 API 명세

> **작성일:** 2026-04-12  
> **작성자:** 김응서  
> **최종 수정일:** 2026-04-28

---

## 1. API 목록

| 우선순위 | API | 설명 |
| --- | --- | --- |
| P1 | `GET /users/me` | 내 정보 조회 |
| P1 | `PATCH /users/me/onboarding` | 온보딩 완료 정보 저장 |
| P1 | `PATCH /users/me/settings` | 사용자 설정 수정 |

---

## 2. 내 정보 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `GET` |
| URL | `/users/me` |
| 인증 | 필요 |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |

#### Query Parameter

> 없음

#### Body

> 없음

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| userId | string(UUID) | N | 사용자 ID |
| nickname | string | Y | 소셜 제공자에서 받은 이름 또는 닉네임 |
| socialProvider | string | N | 소셜 제공자 |
| selectedPrimaryUserType | string | Y | 1차 사용자 유형. 온보딩 미완료 시 `null` |
| selectedMobilitySubtype | string | Y | 보행약자 세부 유형. `selectedPrimaryUserType=MOBILITY_IMPAIRED`일 때만 값 존재 |
| onboardingCompleted | boolean | N | 온보딩 완료 여부 |
| termsAgreed | boolean | N | 필수 약관 동의 여부 |
| ttsEnabled | boolean | N | 음성 안내 여부 |
| routeCollectionEnabled | boolean | N | 경로 데이터 수집 동의 여부 |

#### 비고

- `selectedPrimaryUserType=null`은 소셜 로그인 직후 온보딩을 아직 끝내지 않은 임시 상태에서만 허용한다.
- `onboardingCompleted=false`인 사용자는 지도/경로 탐색 등 서비스 핵심 기능에 진입할 수 없다.
- `selectedPrimaryUserType` 후보값은 `LOW_VISION`, `MOBILITY_IMPAIRED`다.
- `selectedPrimaryUserType=LOW_VISION`이면 `selectedMobilitySubtype=null`이다.
- `selectedPrimaryUserType=MOBILITY_IMPAIRED`이면 `selectedMobilitySubtype`은 한 개만 저장한다. 후보값은 `POWER_WHEELCHAIR`, `MANUAL_WHEELCHAIR`, `OTHER_MOBILITY`다.
- 푸시 알림과 진동 알림 설정은 서버에 저장하지 않는다.

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "userId": "018f7f6c-2b7e-7c3a-9f4a-8b4e3b7c9a01",
    "nickname": "응서",
    "socialProvider": "KAKAO",
    "selectedPrimaryUserType": "MOBILITY_IMPAIRED",
    "selectedMobilitySubtype": "MANUAL_WHEELCHAIR",
    "onboardingCompleted": true,
    "termsAgreed": true,
    "ttsEnabled": true,
    "routeCollectionEnabled": false
  },
  "message": "정상 처리되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 404 | U4040 | 사용자를 찾을 수 없습니다. | 사용자 정보가 존재하지 않음 |

## 3. 온보딩 완료 정보 저장

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `PATCH` |
| URL | `/users/me/onboarding` |
| 인증 | 필요 |
| 설명 | 온보딩에서 선택한 1차 사용자 유형, 보행약자 세부 유형, 약관 동의를 저장하고 온보딩 완료 상태로 전환한다. 별도 프로필 입력 화면은 두지 않는다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |
| Content-Type | Y | `application/json` |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| selectedPrimaryUserType | string | Y | 1차 사용자 유형. `LOW_VISION`, `MOBILITY_IMPAIRED` 중 하나 |
| selectedMobilitySubtype | string | 조건부 | 보행약자 세부 유형. `selectedPrimaryUserType=MOBILITY_IMPAIRED`이면 필수, `LOW_VISION`이면 `null` 또는 미전송 |
| termsAgreed | boolean | Y | 필수 약관 동의 여부. `true`만 온보딩 완료 가능 |

#### 비고

- 서버는 단계별 온보딩 완료 상태를 저장하지 않고 최종 완료 여부만 저장한다.
- 약관은 `termsAgreed` 단순 동의 여부만 저장한다.
- `nickname`은 소셜 제공자에서 받은 이름 또는 닉네임을 사용하므로 이 API에서 받지 않는다.
- `selectedPrimaryUserType=LOW_VISION`이면 서버는 `selectedMobilitySubtype`을 저장하지 않는다.
- `selectedPrimaryUserType=MOBILITY_IMPAIRED`이면 `selectedMobilitySubtype`이 반드시 필요하다.

#### Request Example

```json
{
  "selectedPrimaryUserType": "MOBILITY_IMPAIRED",
  "selectedMobilitySubtype": "MANUAL_WHEELCHAIR",
  "termsAgreed": true
}
```

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| userId | string(UUID) | N | 사용자 ID |
| selectedPrimaryUserType | string | N | 저장된 1차 사용자 유형 |
| selectedMobilitySubtype | string | Y | 저장된 보행약자 세부 유형. 저시력자는 `null` |
| onboardingCompleted | boolean | N | 온보딩 완료 여부 |
| termsAgreed | boolean | N | 필수 약관 동의 여부 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "userId": "018f7f6c-2b7e-7c3a-9f4a-8b4e3b7c9a01",
    "selectedPrimaryUserType": "MOBILITY_IMPAIRED",
    "selectedMobilitySubtype": "MANUAL_WHEELCHAIR",
    "onboardingCompleted": true,
    "termsAgreed": true
  },
  "message": "정상 처리되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | U4000 | 사용자 요청값이 올바르지 않습니다. | 사용자 유형 조합 오류, `selectedMobilitySubtype` 형식 오류 또는 약관 미동의 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 404 | U4040 | 사용자를 찾을 수 없습니다. | 사용자 정보가 존재하지 않음 |

## 4. 사용자 설정 수정

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `PATCH` |
| URL | `/users/me/settings` |
| 인증 | 필요 |
| 설명 | TTS와 경로 데이터 수집 동의를 수정한다. 푸시 알림과 진동 알림은 앱 내부 설정으로 관리한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |
| Content-Type | Y | `application/json` |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| ttsEnabled | boolean | N | 음성 안내 여부 |
| routeCollectionEnabled | boolean | N | 경로 데이터 수집 동의 여부 |

#### Request Example

```json
{
  "ttsEnabled": true,
  "routeCollectionEnabled": false
}
```

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| ttsEnabled | boolean | N | 음성 안내 여부 |
| routeCollectionEnabled | boolean | N | 경로 데이터 수집 동의 여부 |

#### Success Example

```json
{
  "status": "S2000",
  "data": {
    "ttsEnabled": true,
    "routeCollectionEnabled": false
  },
  "message": "정상 처리되었습니다."
}
```

### Error

| HTTP Status | status | message | 발생 조건 |
| --- | --- | --- | --- |
| 400 | U4000 | 사용자 요청값이 올바르지 않습니다. | 설정 필드 타입 오류 |
| 401 | A4010 | 인증이 필요합니다. | 토큰 누락/만료 |
| 404 | U4040 | 사용자를 찾을 수 없습니다. | 사용자 정보가 존재하지 않음 |
