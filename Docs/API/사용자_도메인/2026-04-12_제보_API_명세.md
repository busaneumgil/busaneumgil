## 1. API 목록

| 우선순위 | API | 설명 |
| --- | --- | --- |
| P1 | `POST /hazard-reports` | 도로 상태 제보 등록 |
| P2 | `GET /hazard-reports/me` | 내 제보 목록 조회 |
| P2 | `GET /hazard-reports/{reportId}` | 제보 상세 조회 |
| P2 | `PATCH /hazard-reports/{reportId}` | 제보 수정 |
| P2 | `DELETE /hazard-reports/{reportId}` | 제보 삭제/취소 |

---

## 2. 도로 상태 제보 등록

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P1 |
| Method | `POST` |
| URL | `/hazard-reports` |
| 인증 | 필요 |
| 설명 | 도로 공사, 장애물, 점자블록 손상 등을 제보한다. 파일 업로드는 제외하고 이미지 URL 배열만 고려한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |
| Content-Type | Y | `application/json` |

#### Body

| 필드명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| reportType | string | Y | 제보 유형. `CONSTRUCTION`, `OBSTACLE`, `DAMAGE`, `OTHER` |
| description | string | N | 설명 |
| reportPoint | object | Y | 제보 위치 |
| reportPoint.lat | number | Y | 위도 |
| reportPoint.lng | number | Y | 경도 |
| address | string | N | 주소 |
| imageUrls | array | N | 제보 이미지 URL 목록 |

### Response

- HTTP Status: `201 Created`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| reportId | Long | N | 제보 ID |
| status | string | N | 제보 상태. 기본값 `PENDING` |

---

## 3. 내 제보 목록 조회

| 항목 | 내용 |
| --- | --- |
| 우선순위 | P2 |
| Method | `GET` |
| URL | `/hazard-reports/me` |
| 인증 | 필요 |
| 설명 | 현재 사용자가 등록한 제보 목록을 조회한다. 관리자 화면에서는 사용자 정보를 익명 처리한다. |

### Request

#### Header

| 이름 | 필수 | 설명 |
| --- | --- | --- |
| Authorization | Y | Bearer 액세스 토큰 |

#### Query Parameter

| 변수명 | 타입 | 필수 | 설명 |
| --- | --- | --- | --- |
| page | int | N | 페이지 번호 |
| size | int | N | 페이지 크기 |
| status | string | N | 제보 상태. `PENDING`, `APPROVED`, `REJECTED` |

### Response

- HTTP Status: `200 OK`

| 필드명 | 타입 | Null 가능 | 설명 |
| --- | --- | --- | --- |
| content | array | N | 제보 목록 |
| content[].reportId | Long | N | 제보 ID |
| content[].reportType | string | N | 제보 유형 |
| content[].address | string | Y | 주소 |
| content[].status | string | N | 제보 상태 |
